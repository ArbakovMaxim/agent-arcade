# Arcade — дошки завдань, блокнот, чати команди та ігри всередині Claude Code

[English](README.md) · [Русский](README.ru.md) · **Українська** · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [한국어](README.ko.md)

> **Бета (0.36).** Усе, що тут описано, працює й щодня в ділі; далі змінюються здебільшого деталі. Повідомлення про помилки дуже вітаються — див. [Відгуки](#відгуки).

Arcade — плагін для [Claude Code](https://claude.com/claude-code), який перетворює його на невелике робоче місце: дошки проєктів, де будь-яку картку можна однією кнопкою віддати Claude, блокнот, який Claude веде разом із тобою і який спільний для всіх відкритих сесій, а також спільні дошки й чати для команди. А поки чекаєш: коли агент зайнятий довше за 10 секунд, над полем вводу з’являється невелике *«зіграти?»*. Зіграй у гру — NES, Sega, PlayStation, Doom, шахи та інше, — почитай книгу, послухай аудіокнигу чи подкаст або подивись відео на тему роботи агента. Arcade повідомить тієї ж миті, коли агент закінчить або попросить дозволу, — нічого не пропустиш.

Усе в каталозі безкоштовне: ігри мають відкриті ліцензії, книги й аудіокниги — у суспільному надбанні. Можна також грати по мережі з іншими людьми, які теж чекають на своїх агентів, і листуватися з друзями.

## Можливості

- **Блокнот і дошки проєктів.** Сторінки, підсторінки й чек-листи, які веде й Claude, і дошки з колонками й картками. *Віддати Claude* передає Claude сторінку чи картку: він позначає зроблене й дописує підсумок туди ж. Сторінка чи картка показує текст відформатованим, з кнопками *Змінити* й *Копіювати*. Блокнот спільний для всіх відкритих сесій Claude Code, тож кожна може взяти свою картку з однієї дошки. Поділися дошкою з друзями — і всі працюють на одній. Сторінку можна надіслати в Notion чи інший застосунок або забрати звідти через конектори Claude; надиктуй у поле введення Claude й перенеси текст на сторінку.
- **Друзі й чати.** Необов’язковий вхід через GitHub робить налаштування однаковими на всіх твоїх комп’ютерах і дає @нік; додавай друзів за точним ніком, дивись, хто в мережі, ділися дошками, запрошуй зіграти й листуйся віч-на-віч або в групах.
- **Знає, що робить агент.** Коли агент закінчив або просить дозволу, над грою з’являється банер — грай далі, постав паузу або одразу повертайся до агента (поведінку обираєш у налаштуваннях). У Claude Desktop Arcade може ще й закрити вкладку, де ти дивишся, — і перед тобою знову розмова.
- **З’являється сам.** Після 10 секунд роботи агента Arcade пропонує гру над полем вводу — або пізніше, або ніколи, як обереш у налаштуваннях; фокус не забирає, доки ти про це не попросиш.
- **Іде за тобою із сесії в сесію.** Залиш панель Arcade відкритою — і кожна нова сесія Claude Code відкриє її сама; закрий її вручну — і вона лишиться закритою.
- **Одне меню, шість розділів.** *Грати*, *Читати й слухати*, *Дивитися*, *Спілкування*, *Робота* і *Ще* — згорни ті, що не потрібні. Угорі: *Продовжити* останню гру, *Знайти* та *Обране*. Під час першого запуску Arcade спитає, які розділи показувати.
- **61 безкоштовна гра**: NES (Dendy), Sega Mega Drive, Master System, PlayStation і вкладка *Ігри* з аркадами, шутерами, перегонами, стратегіями, квестами й настільними іграми.
- **Читай і слухай.** Класика й аудіокниги LibriVox 30 мовами — просто з Project Gutenberg, Wikisource і LibriVox, а ще свіжі статті й випуски подкастів на тему роботи агента.
- **Дивись.** Свіжі відео YouTube на тему роботи агента, Twitch: твої канали та трансляції про програмування, технології, науку й ретроігри, і TikTok: стрічка *Для тебе* та пошук на самому сайті TikTok, куди ти входиш сам.
- **NES і Flappy Arcade прямо в Claude Code** — у терміналі, VS Code і Claude Desktop. Решта відкривається у вікні браузера — у Claude Desktop за замовчуванням у вбудованому браузері Claude (шутери все одно відкриваються у вікні браузера: вбудований браузер не захоплює мишу).
- **Гра по мережі.** Ігри на двох для приставок по мережі, Doom — deathmatch і кооператив, шахи, го, шашки й реверсі проти людей або комп’ютера.
- **«Хто чекає онлайн».** Arcade показує в Claude Code, коли хтось чекає на партнера, з кнопкою *Приєднатися*.
- **Пошук і обране.** Один пошук по іграх і каналах Twitch, згрупований за розділами й жанрами; познач гру зірочкою ☆, щоб вона була в *★ Обране*.
- **Свої ігри.** Додавай ROM, які в тебе є; вони залишаються на твоєму комп’ютері.
- **13 мов інтерфейсу:** English, Русский, Українська, Español, Français, Deutsch, Português, Italiano, Polski, Türkçe, 日本語, 中文, 한국어 — за мовою системи чи браузера, за замовчуванням англійська.

## Встановлення

Потрібен **Claude Code 2.1.275 або новіший**.

У терміналі — дві команди: додай маркетплейс Arcade (цей репозиторій), потім установи з нього плагін:

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

Або всередині сесії Claude Code:

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

Плагін встановлюється для всіх сесій і застосунків. У розширенні VS Code немає команди `/plugin` — встанови з термінала, і розширення підхопить плагін у новій розмові.

**Оновлення:**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

Потім перезапусти Claude Code. Маркетплейс завантажує лише плагін — кілька МіБ, без сайту, — тож оновлення займає секунди. Якщо Arcade вже встановлено, нічого робити не треба: маркетплейс перемкнеться сам під час наступного оновлення.

Якщо `/plugin update` пише *already at the latest version*, а нова версія Arcade вже вийшла, — маркетплейс не оновився. Причину покаже `claude plugin marketplace update agent-arcade` у терміналі. Якщо там *timed out*, дай клонуванню 10 хвилин:

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

У PowerShell: `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade`. Потім знову `/plugin update arcade@agent-arcade`.

**Видалення:** `/plugin uninstall arcade@agent-arcade`

## Як користуватися

- **`/arcade`** відкриває меню будь-коли.
- Залиш панель відкритою — і нові сесії відкриватимуть її самі: у терміналі — під час запуску, у Desktop і VS Code — коли під’єднаються до сесії; клавіатура лишається за полем вводу. Закрий її вручну (хрестиком або Esc) — і вона перестане відкриватися сама, доки ти знову її не відкриєш.
- Коли агент працює довше за 10 секунд, над полем вводу з’являється *«зіграти?»*: **`1`** — грати тут, у панелі; **`2`** — у вікні браузера (де можна); **`3`** — не зараз. Через скільки показувати цей рядок — від 10 секунд до 5 хвилин — чи не показувати зовсім, вибирається в «Налаштування → Сповіщення».
- Стрілки або Tab — вибір, Enter — відкрити; миша теж працює. Керування показано під кожною грою.
- Коли агент закінчив або чекає на дозвіл, над грою з’являється банер: **До агента** або **Грати далі**.

Після входу в шапці меню видно твій @нік із тими самими лічильниками.

**Пошук** працює від двох літер і шукає за назвою або жанром, без урахування регістру й діакритики. Результати згруповано за розділами й жанрами, як-от *Ігри · Шутери*. Зірочка ☆ біля гри додає її в **★ Обране** (до 100), розкладене за розділами й жанрами, найновіші — першими. У книг і аудіокниг — свій пошук, за назвою або автором.

## Блокнот і дошки проєктів

Обидва — у розділі *Робота* меню.

- **Блокнот.** Сторінки й підсторінки; рядок, що починається з `# `, — заголовок, з `- ` — пункт, з `- [ ] ` — пункт чек-листа, який відмічається натисканням. Зберігається на цьому комп’ютері — до 200 сторінок, 20 000 знаків на сторінці.
- **Змінити й копіювати.** Сторінка чи картка показує текст відформатованим — заголовки, списки, чек-лист — у Desktop і VS Code, а в терміналі — рядками. *Змінити* відкриває на її місці поле з текстом: Enter зберігає, *Скасувати* відкидає зміну, а те, що тим часом змінить Claude чи інша сесія, з’являється в полі. *Копіювати* кладе всю сторінку в буфер обміну — у панелі Desktop виділити текст можна лише в полях введення, тож сторінку копіюють саме так.
- **Claude теж його веде.** *Віддати Claude* передає сторінку Claude, або просто попроси Claude записати щось в Arcade. Claude користується інструментом `mcp__arcade__notes`, який змінює лише блокнот і нічого не видаляє. Не сподобалася правка Claude — *Повернути текст до правки Claude*.
- **Notion та інші застосунки** — через конектори Claude, тож Arcade не потрібні ключі чи паролі: *Надіслати в Notion*, *В інший застосунок*, *Забрати з Notion або іншого застосунку*. Пов’язану сторінку можна оновити в застосунку або знову забрати звідти.
- **Голосом.** Надиктуй у поле введення Claude системним диктуванням (Win+H у Windows, двічі Fn у macOS) і натисни *Взяти з поля введення Claude* — текст перейде в кінець сторінки.
- **Дошка проєктів.** Колонки — *Зробити*, *В роботі*, *Готово* або свої, до 8, — і картки; картка — це сторінка блокнота з текстом і чек-листом. Натисни на картку, щоб вибрати її й переносити стрілками, ще раз — щоб відкрити. Claude теж веде дошки: *Віддати Claude* або попроси його розкласти завдання по дошці в Arcade.
- **Спільні дошки.** Якщо ти ввійшов з @ніком, познач друзів і натисни *Поділитися*: картки, колонки й назва в усіх однакові, а зміни доходять за лічені секунди. Власник запрошує ще друзів, прибирає учасників і видаляє дошку з сайту; вийти може будь-хто; хай що станеться, у кожного лишається своя копія. Власних спільних дошок — до 3, на дошці — до 20 людей і 200 карток.
- **Кілька сесій одразу.** Усі відкриті сесії Claude Code на цьому комп’ютері працюють з одним блокнотом і його дошками: що одна додала, змінила чи позначила, інші бачать за кілька секунд, тож кожна сесія може вести свою картку однієї дошки.

## Для команд

Невелика команда може вести свої завдання в Arcade: одна спільна дошка, а хто бере картку, віддає її своєму Claude.

1. Кожен встановлює Arcade (Claude Code 2.1.275 або новіший) — див. [Встановлення](#встановлення).
2. `/arcade` → **Спілкування** → **Увійти через GitHub**: сторінка GitHub відкривається в браузері — підтверди вхід там, потім натисни *Sign in* на сторінці Arcade (код на ній має збігатися з кодом у панелі). Якщо не виходить — *Увійти за кодом*.
3. Візьми @нік — ім’я з GitHub одним натисканням або своє.
4. Додай колег у друзі за точним @ніком; вони приймають запит у себе.
5. **Робота** → створи дошку → познач колег → **Поділитися**.
6. Потрібні лише дошки й чати? Під час першого запуску Arcade залиш тільки **Робота** і **Спілкування**. Потім у **Налаштування → Сповіщення** натискай **Рядок «зіграти?»**, доки не з’явиться *вимкнено*: поки агент працює, над полем вводу нічого не з’являтиметься.

Далі так: відкрий дошку, вибери картку, **Віддати Claude**. Якщо Claude вільний, картка одразу йде до нього; якщо зайнятий — чекає в полі вводу, доки ти її не надішлеш. Claude позначає зроблене й дописує підсумок на картку, і всі на дошці бачать це за лічені секунди. Чати — у розділі **Спілкування**.

Варто знати: спільні дошки й чати зберігаються на сайті Arcade і не шифруються, тож не тримай там паролів і ключів. Arcade дізнається лише ім’я та зображення твого профілю GitHub. Власних спільних дошок — до 3, на дошці — до 20 людей і 200 карток. *Видалити акаунт* (натиснути двічі) — сайт забуває тебе й твої налаштування.

## Акаунт, друзі й чати

Вхід необов’язковий — без нього все інше працює як раніше.

- **Увійти через GitHub** (у розділі *Спілкування*): сторінка входу GitHub відкривається у твоєму звичайному браузері — підтверди вхід там, потім натисни *Sign in* на сторінці Arcade; код на ній має збігатися з кодом у панелі. ## Що плагін робить на твоєму комп’ютері

Arcade працює всередині Claude Code з тими правами, які Claude Code дає плагінам. Увесь його код — у цьому репозиторії, а `claude plugin validate ./mod` перелічує кожну подію, на яку він підписаний, і кожен виклик. Коротко:

- **Інструменти агента.** Arcade бачить, коли інструмент починається й закінчується і коли агент просить дозволу, — так він знає, коли показати банер. Виклики інструментів агента він ніколи не змінює й не блокує. Сам він дозволяє лише два види викликів і лише там, де Claude Code інакше спитав би тебе: `mcp__arcade__notes`, який змінює лише блокнот і нічого не видаляє, та відкриття гри у вбудованому браузері Desktop після твого натискання в панелі. Твої правила дозволу й заборони діють як є.
- **Зупинка агента.** Лише в Claude Desktop, коли ти відкриваєш щось у вбудованому браузері, поки агент працює: Desktop не дає плагіну відкрити браузер самому. Arcade чекає, доки закінчиться поточний інструмент (через 10 секунд обриває його, але чекає, поки на екрані запит дозволу), зупиняє агента й просить Claude відкрити сторінку та повернутися до роботи. Щоб такого не було, обери вікно браузера в *Налаштування → Де відкривати ігри*.
- **Твоя розмова.** Для тем Haiku у твоїй власній сесії отримує кінець розмови — кілька тисяч символів; це йде у твоє використання Claude. Сайт Arcade розмови не бачить. У поле введення Arcade пише чи надсилає його лише на твоє прохання — наприклад, *Віддати Claude* у блокноті — або щоб відкрити сторінку, як описано вище.
- **Програми.** Твій браузер для вікна Arcade (у Windows — з окремим профілем у `%LOCALAPPDATA%\claude-arcade`); сповіщення — PowerShell у Windows, `osascript` у macOS, `notify-send` у Linux; перевірка, які браузери встановлено (Windows) або яка це ОС (`uname`).
- **Файли.** Записує лише ROM, які ти додаєш через `/arcade-add`, — у `~/.claude/arcade/roms`; читає лише названий тобою файл, ці копії та власні файли. Налаштування, блокнот і обране лежать у сховищі плагінів Claude Code.
- **Змінні середовища.** Читає `HOME` або `USERPROFILE`, `LANG`, `LC_ALL`, `LC_MESSAGES`, `LOCALAPPDATA` та `OS`; жодної не змінює.
- **Мережа.** Сам плагін звертається лише до сайту Arcade (`agent-arcade.fefaodessa.workers.dev`), до RSS-стрічок каналів YouTube і до стрічок блогів і подкастів, які показує. Картинки в панелі Desktop, як-от аватарки Twitch, вантажаться просто з цих сервісів. Ігри, книжки й відео завантажує сторінка, відкрита в браузері.

## Розробникам

```
mod/     плагін Claude Code (хуки, інтерфейс панелі, тести)
site/    сайт на Cloudflare Workers: каталог, вікно Arcade, мережеві кімнати, акаунти, друзі, чати, звіти про помилки
tools/   допоміжні збирачі: переклади, heretic-wasm
.github/ GitHub Actions, що збирають doom-wasm, heretic-wasm, OpenTTD і ScummVM для браузера
```

- Запуск плагіна з репозиторію: `claude --plugin-dir ./mod`
- Тести плагіна: `claude plugin validate ./mod`, потім `claude plugin test` у `mod/`
- Тести сайту: `npm test` у `site/`; збірка: `node build.mjs`; деплой відбувається автоматично з `main` через Cloudflare Workers Builds.
- Робота йде в `main`, pull request'и — туди ж. Гілка за замовчуванням `plugin` — копія `main` без `site/`, яку GitHub Action оновлює на кожен пуш: маркетплейс плагінів завантажує її, а не весь репозиторій.
- Переклади: `node tools/i18n/collect.mjs`, потім `node tools/i18n/check.mjs` — див. [tools/i18n/README.md](tools/i18n/README.md).

Докладна документація (російською): [mod/README.md](mod/README.md) — плагін, [site/README.md](https://github.com/ArbakovMaxim/agent-arcade/tree/main/site/README.md) — сайт, додавання ігор і гра по мережі.
