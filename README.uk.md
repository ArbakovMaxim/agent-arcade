# Arcade — дошки завдань, блокнот, чати команди та ігри всередині Claude Code

[English](README.md) · [Русский](README.ru.md) · **Українська** · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [한국어](README.ko.md)

> **Бета (0.39).** Усе, що тут описано, працює й щодня в ділі; далі змінюються здебільшого деталі. Повідомлення про помилки дуже вітаються — див. [Відгуки](#відгуки).

Arcade — плагін для [Claude Code](https://claude.com/claude-code), який перетворює його на невелике робоче місце: дошки проєктів, де Claude бере картки одну за одною, навіть у кількох сесіях одночасно; блокнот, який Claude веде разом із тобою і який спільний для всіх відкритих сесій; календар; а також спільні дошки й чати для команди. А поки чекаєш: коли агент зайнятий довше за 10 секунд, над полем вводу з’являється невелике *«зіграти?»*. Зіграй у гру — NES, Sega, PlayStation, Doom, шахи та інше, — почитай книгу, послухай аудіокнигу чи подкаст або подивись відео на тему роботи агента. Arcade повідомить тієї ж миті, коли агент закінчить або попросить дозволу, — нічого не пропустиш.

Усе в каталозі безкоштовне: ігри мають відкриті ліцензії, книги й аудіокниги — у суспільному надбанні. Можна також грати по мережі з іншими людьми, які теж чекають на своїх агентів, і листуватися з друзями.

## Можливості

- **Блокнот і дошки проєктів.** Сторінки, підсторінки й чек-листи, які веде й Claude, і дошки з колонками й картками. *Віддати Claude* передає Claude сторінку чи картку: він позначає зроблене й дописує підсумок туди ж. Сторінка чи картка показує текст відформатованим, з кнопками *Змінити* й *Копіювати*. Блокнот спільний для всіх відкритих сесій Claude Code, тож кожна може взяти свою картку з однієї дошки. Поділися дошкою з друзями — і всі працюють на одній. Сторінку можна надіслати в Notion чи інший застосунок або забрати звідти через конектори Claude; надиктуй у поле введення Claude й перенеси текст на сторінку.
- **Claude проходить твою дошку.** *Черга для Claude* віддає Claude картки першої колонки по одній: наступна йде, коли попередня вже в *Готово*, а запитання Claude або недороблена картка зупиняють чергу. У карток є терміни, їх видно в календарі, а на спільній дошці всі бачать, хто яку картку взяв. Задачі GitHub приходять на дошку картками, а підсумок іде назад коментарем — через конектор GitHub у Claude. *Підсумки дня* збирають сторінку для стендапу — що пішло Claude, що зроблено, що в роботі, — щоб надіслати її в чат команди.
- **Агенти.** Вкладка *Агенти* в розділі *Робота* показує всі сесії Claude Code з Arcade на цьому комп’ютері — за папкою: працює, чекає дозволу, закінчив хід чи вільна і скільки часу, з її карткою та місцем у черзі. Коли Claude в іншій сесії ставить запитання з варіантами, відповіси кнопкою просто в її картці. Коли інша сесія просить дозволу або ставить запитання, про це скаже спливне повідомлення у твоїй же панелі. Черга дошки може йти в кількох сесіях одразу, і одну картку дві сесії не отримають.
- **Ліміти.** Плитка *Ліміти* в розділі *Робота* показує вікна лімітів Claude — 5 годин, тиждень і ліміт витрат — з відсотком, смужкою й часом скидання кожного, а ще контекст і витрати цієї та інших твоїх сесій. Цифри — від самого Claude Code. Якщо ліміт закінчився посеред черги дошки, одна кнопка продовжить її після скидання.
- **Календар.** У Desktop — місяць із плиток днів однакового розміру з крапкою кольору кожної події, у терміналі й VS Code — список найближчого. Подію записують одним рядком, наприклад «fri 9:30 standup», і вона може повторюватися щодня, по буднях, щотижня, щомісяця або щороку. Обери їй колір і коли нагадати — зі списку або своїми словами (наприклад, «45 min before» чи «the day before at 20:00»); нагадування приходить системним сповіщенням. Тут же й терміни карток дошок. Claude теж записує й змінює події: «запиши дзвінок у п’ятницю о 15:00».
- **Друзі й чати.** Необов’язковий вхід через GitHub робить налаштування однаковими на всіх твоїх комп’ютерах і дає @нік; додавай друзів за точним ніком, дивись, хто в мережі, ділися дошками, запрошуй зіграти й листуйся віч-на-віч або в групах.
- **Знає, що робить агент.** Коли агент закінчив або просить дозволу, над грою з’являється банер — грай далі, постав паузу або одразу повертайся до агента (поведінку обираєш у налаштуваннях). У Claude Desktop Arcade може ще й закрити вкладку, де ти дивишся, — і перед тобою знову розмова.
- **З’являється сам.** Після 10 секунд роботи агента Arcade пропонує гру над полем вводу — або пізніше, або ніколи, як обереш у налаштуваннях; фокус не забирає, доки ти про це не попросиш.
- **Іде за тобою із сесії в сесію.** Залиш панель Arcade відкритою — і кожна нова сесія Claude Code відкриє її сама; закрий її вручну — і вона лишиться закритою.
- **Одне меню, шість розділів.** *Грати*, *Читати й слухати*, *Дивитися*, *Спілкування*, *Робота* і *Ще* — згорни ті, що не потрібні. Угорі: *Продовжити* останню гру, *Знайти* та *Обране*. Під час першого запуску Arcade спитає, які розділи показувати.
- **61 безкоштовна гра**: NES (Dendy), Sega Mega Drive, Master System, PlayStation і вкладка *Ігри* з аркадами, шутерами, перегонами, стратегіями, квестами й настільними іграми.
- **Читай і слухай.** Класика й аудіокниги LibriVox 30 мовами — просто з Project Gutenberg, Wikisource і LibriVox, а ще свіжі статті й випуски подкастів на тему роботи агента.
- **Дивись.** Свіжі відео YouTube на тему роботи агента, Twitch: твої канали та трансляції про програмування, технології, науку й ретроігри, і TikTok: стрічка *Для тебе* та пошук на самому сайті TikTok, куди ти входиш сам.
- **NES і Flappy Arcade прямо в Claude Code** — у терміналі, VS Code і Claude Desktop. Решта відкривається у вікні браузера — у Claude Desktop за замовчуванням у вбудованому браузері Claude (шутери все одно відкриваються у вікні браузера: вбудований браузер не захоплює мишу).
- **Гра по мережі.** Ігри на двох для приставок по мережі, Doom — deathmatch і кооператив, шахи, го, шашки й реверсі проти людей або комп’ютера.
- **«Хто чекає онлайн».** Arcade показує в Claude Code, коли хтось чекає на партнера, з кнопкою *Приєднатися*.
- **Пошук і обране.** Один пошук по іграх і каналах Twitch, згрупований за розділами й жанрами; познач гру зірочкою ☆, щоб вона була в *★ Обране*.
- **Свої ігри.** Додавай ROM, які в тебе є; вони залишаються на твоєму комп’ютері.
- **13 мов інтерфейсу:** English, Русский, Українська, Español, Français, Deutsch, Português, Italiano, Polski, Türkçe, 日本語, 中文, 한국어 — за мовою системи чи браузера, за замовчуванням англійська.

## Встановлення

Потрібен **Claude Code 2.1.275 або новіший**. *Лімітам* потрібен Claude Code, який повідомляє ліміти плагінам (перевірено на 2.1.302 і 2.1.316); у старішому цей екран так і скаже, а решта Arcade працює як звичайно.

У терміналі — дві команди: додай маркетплейс Arcade (цей репозиторій), потім установи з нього плагін:

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

Або всередині сесії Claude Code:

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

Плагін встановлюється для всіх сесій і застосунків. У розширенні VS Code немає команди `/plugin` — встанови з термінала, і розширення підхопить плагін у новій розмові.

**Оновлення:**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

Потім перезапусти Claude Code. Маркетплейс завантажує лише плагін — кілька МіБ, без сайту, — тож оновлення займає секунди. Якщо Arcade вже встановлено, нічого робити не треба: маркетплейс перемкнеться сам під час наступного оновлення.

Якщо `/plugin update` пише *already at the latest version*, а нова версія Arcade вже вийшла, — маркетплейс не оновився. Причину покаже `claude plugin marketplace update agent-arcade` у терміналі. Якщо там *timed out*, дай клонуванню 10 хвилин:

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

У PowerShell: `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade`. Потім знову `/plugin update arcade@agent-arcade`.

**Видалення:** `/plugin uninstall arcade@agent-arcade`

## Як користуватися

- **`/arcade`** відкриває меню будь-коли.
- Залиш панель відкритою — і нові сесії відкриватимуть її самі: у терміналі — під час запуску, у Desktop і VS Code — коли під’єднаються до сесії; клавіатура лишається за полем вводу. Закрий її вручну (хрестиком або Esc) — і вона перестане відкриватися сама, доки ти знову її не відкриєш.
- Коли агент працює довше за 10 секунд, над полем вводу з’являється *«зіграти?»*: **`1`** — грати тут, у панелі; **`2`** — у вікні браузера (де можна); **`3`** — не зараз. Через скільки показувати цей рядок — від 10 секунд до 5 хвилин — чи не показувати зовсім, вибирається в «Налаштування → Сповіщення».
- Стрілки або Tab — вибір, Enter — відкрити; миша теж працює. Керування показано під кожною грою.
- Коли агент закінчив або чекає на дозвіл, над грою з’являється банер: **До агента** або **Грати далі**.

Натисни заголовок розділу, щоб згорнути чи розгорнути його. Згорнутий розділ показує `▸` і скільки в ньому плиток, а *Спілкування* — ще й нові повідомлення 💬 і запити в друзі 👥. Arcade пам’ятає, які розділи згорнуто. Непотрібний розділ можна прибрати в **Налаштуваннях**: його не буде в меню зовсім — ні заголовка, ні плиток; *Ще* з налаштуваннями лишається завжди. Після входу в шапці меню видно твій @нік із тими самими лічильниками.

**Пошук** працює від двох літер і шукає за назвою або жанром, без урахування регістру й діакритики. Результати згруповано за розділами й жанрами, як-от *Ігри · Шутери*. Зірочка ☆ біля гри додає її в **★ Обране** (до 100), розкладене за розділами й жанрами, найновіші — першими. У книг і аудіокниг — свій пошук, за назвою або автором.

## Блокнот і дошки проєктів

Обидва — у розділі *Робота* меню.

- **Блокнот.** Сторінки й підсторінки; рядок, що починається з `# `, — заголовок, з `- ` — пункт, з `- [ ] ` — пункт чек-листа, який відмічається натисканням. Зберігається на цьому комп’ютері — до 200 сторінок, 20 000 знаків на сторінці.
- **Змінити й копіювати.** Сторінка чи картка показує текст відформатованим — заголовки, списки, чек-лист — у Desktop і VS Code, а в терміналі — рядками. *Змінити* відкриває на її місці поле з текстом: Enter зберігає, *Скасувати* відкидає зміну, а те, що тим часом змінить Claude чи інша сесія, з’являється в полі. *Копіювати* кладе всю сторінку в буфер обміну — у панелі Desktop виділити текст можна лише в полях введення, тож сторінку копіюють саме так.
- **Claude теж його веде.** *Віддати Claude* передає сторінку Claude, або просто попроси Claude записати щось в Arcade. Claude користується інструментом `mcp__arcade__notes`, який змінює лише блокнот і нічого не видаляє. Не сподобалася правка Claude — *Повернути текст до правки Claude*.
- **Notion та інші застосунки** — через конектори Claude, тож Arcade не потрібні ключі чи паролі: *Надіслати в Notion*, *В інший застосунок*, *Забрати з Notion або іншого застосунку*. Пов’язану сторінку можна оновити в застосунку або знову забрати звідти.
- **Голосом.** Надиктуй у поле введення Claude системним диктуванням (Win+H у Windows, двічі Fn у macOS) і натисни *Взяти з поля введення Claude* — текст перейде в кінець сторінки.
- **Дошка проєктів.** Колонки — *Зробити*, *В роботі*, *Готово* або свої, до 8, — і картки; картка — це сторінка блокнота з текстом і чек-листом. Натисни на картку, щоб вибрати її й переносити стрілками, ще раз — щоб відкрити. Claude теж веде дошки: *Віддати Claude* або попроси його розкласти завдання по дошці в Arcade.
- **Спільні дошки.** Якщо ти ввійшов з @ніком, познач друзів і натисни *Поділитися*: картки, колонки й назва в усіх однакові, а зміни доходять за лічені секунди. Власник запрошує ще друзів, прибирає учасників і видаляє дошку з сайту; вийти може будь-хто; хай що станеться, у кожного лишається своя копія. Власних спільних дошок — до 3, на дошці — до 20 людей і 200 карток.
- **Кілька сесій одразу.** Усі відкриті сесії Claude Code на цьому комп’ютері працюють з одним блокнотом і його дошками: що одна додала, змінила чи позначила, інші бачать за кілька секунд, тож кожна сесія може вести свою картку однієї дошки.
- **Черга для Claude.** На дошці *Черга для Claude* віддає Claude першу картку першої колонки й переносить її в другу колонку, якщо колонок більше двох. Коли Claude закінчує хід, а ця картка вже в останній колонці, наступна йде сама — до 10 карток за запуск. Черга зупиняється, якщо Claude поставив запитання, хід перервали або він закінчився помилкою, картка не в останній колонці або Claude отримав інше прохання — далі вирішуєш ти. Запит дозволу її не зупиняє: якщо дозвіл дали (ти або авто-режим) і картка в останній колонці, наступна йде сама. *Зупинити чергу* дає Claude доробити поточну картку, а наступної він не отримає. На спільній дошці картки, які взяв хтось інший, черга пропускає. Черга може йти в кількох сесіях одразу — див. [Агенти](#агенти). Якщо посеред черги закінчився ліміт Claude, її можна продовжити після скидання — див. [Ліміти](#ліміти).
- **Терміни.** Поле *Термін* картки розуміє «fri», «tomorrow», «20.11» або «2026-11-20». Термін видно під карткою на дошці — кольором попередження, якщо він минув, а картку не зроблено, — і в календарі, який нагадає о 9:00 того дня, якщо картка ще не в останній колонці. Claude теж ставить терміни.
- **Хто взяв картку.** На спільній дошці *Віддати Claude* позначає картку як твою, і всі бачать під нею «у роботі в @нік». Якщо її вже взяв хтось інший, Arcade спершу скаже про це; натисни ще раз — і вона однаково піде твоєму Claude. *Відпустити картку* звільняє її.
- **Задачі GitHub.** Поле *Задачі з GitHub* на дошці приймає `owner/repo` або посилання на задачі: Claude читає до 20 відкритих задач через свій конектор GitHub і заводить картками ті, яких на дошці ще немає. На такій картці *Підсумок — у GitHub* просить Claude написати в задачу короткий коментар про те, що зроблено; задачу він не закриває. Сам Arcade з GitHub не спілкується й ключів не потребує.
- **Підсумки дня.** Кнопка під дошками й у блокноті збирає сторінку «Підсумки ДД.ММ»: що сьогодні пішло Claude, що зроблено — картки, перенесені в останню колонку, і відмічені пункти, — і що ще в роботі. Її можна віддати Claude, виправити або надіслати в чат.
- **Надіслати в чат.** Якщо ти ввійшов, *Надіслати в чат* надсилає будь-яку сторінку в один із твоїх останніх чатів текстом — із заголовками й позначками чек-листа.

## Календар

Він у розділі *Робота* меню. Як і блокнот, календар зберігається на цьому комп’ютері, у сховищі плагінів Claude Code, і він спільний для всіх відкритих сесій.

- **Місяць і день.** У Desktop — сітка місяця з плиток днів однакового розміру зі стрілками й *Сьогодні*: зверху число, під ним крапка кольору кожної події (до трьох, далі «+N»). Вибраний день має виділену рамку, сьогоднішній — підкладку. Під сіткою — події вибраного дня, нижче *Найближче* на 30 днів, картками кольору події. У терміналі й VS Code — список *Найближче*.
- **Подія — одним рядком:** «fri 9:30 standup», «tomorrow 15:00 call», «12.11 review», «2026-11-20 10:00 demo». Без дня — на день, вибраний у сітці (у терміналі — на сьогодні), без часу — на весь день. Слова для днів розуміються англійською й російською.
- **Повтор.** Не повторюється, щодня, по буднях, щотижня, щомісяця або щороку; день події — це день, коли серія починається. Можна й одним рядком: «every friday 10:00 retro», «on weekdays 9:30 standup».
- **Колір.** Синій, зелений, жовтий, помаранчевий, червоний, фіолетовий, рожевий або сірий; типово синій.
- **Нагадування.** Обери зі списку: на початку, за 5, 10, 15 або 30 хвилин, за 1 або 2 години, за добу, дві доби або тиждень; у події на весь день — о 9:00, 8:00 або 7:00 цього дня, напередодні о 21:00, 18:00 або 9:00, за два дні або тиждень о 9:00. Або впиши свій час англійською чи російською: «45 min before», «at 14:30», «the day before at 20:00» — не пізніше за початок і не раніше ніж за тиждень. У застосунку Claude на телефоні, де списку немає, кнопка перебирає варіанти по колу.
- **Сповіщення.** Нагадування приходить системним сповіщенням і спливним рядком, поки відкрита хоч одна сесія Claude Code; показує його одна сесія, а не всі. Пропущене, поки Claude Code був закритий, з’явиться під час наступного запуску як *Пропущено*, якщо подія була менше ніж добу тому.
- **Claude теж його веде** — інструментом `mcp__arcade__calendar`, який змінює лише календар: «запиши дзвінок у п’ятницю о 15:00», «що в мене завтра?», «зроби демо червоним».
- **Терміни карток.** Картки дошок із терміном видно у свій день як події на весь день, з позначкою *зроблено*, коли картка вже в останній колонці; змінюють їх на самій картці.
- З календарями Google і Apple він поки не синхронізується.

## Агенти

Це в розділі *Робота* меню: сесії Claude Code з Arcade на цьому комп’ютері, кожна — за назвою своєї папки, твоя позначена *ця сесія*.

- **Що робить кожна.** *Чекає дозволу*, *чекає відповіді*, *закінчив хід*, *працює* або *вільна* — і скільки часу, з карткою, яку вона робить, і місцем у черзі, наприклад *Черга: картка 3 з 10*. Сесії, які чекають дозволу, — першими. У Desktop кожна сесія — картка, у терміналі й VS Code — рядок. Закрита сесія зникає менш ніж за хвилину.
- **Шукай за папкою.** Відкрити іншу сесію за тебе Arcade не може: назва папки підкаже, яке це вікно чи вкладка.
- **Відповісти звідси.** Коли Claude в іншій сесії ставить запитання з варіантами, її картка показує запитання й варіанти кнопками. Одне запитання йде після першого натискання; якщо їх кілька — вибери варіанти й натисни *Відповісти*. За секунду Claude в тій сесії отримає відповідь так само, як якби відповіли в ній самій. Запит дозволу теж видно — з інструментом і командою, наприклад *Bash: npm test*, — але дозвіл дається лише в самій сесії.
- **Одна черга, кілька сесій.** Натисни *Черга для Claude* на тій самій дошці в кожній сесії — наступну картку візьме та, що вільна; одну картку дві сесії не отримають. Сесія, що приєдналася, так і скаже: *Черга на цій дошці вже йде в сесії «api»*. Кожна сесія зупиняє свою чергу за тими самими правилами — запитання Claude, недороблена картка, перерваний хід, інше прохання — і віддає до 10 карток за запуск. *Зупинити чергу* зупиняє лише цю сесію, *Зупинити всюди* — усі, і кожна доробить поточну картку. Під карткою дошка показує, у кого вона: *у сесії «api»*.
- **Та сама папка.** Якщо сесія, яка вже в черзі, працює в тій самій папці, Arcade попередить, що дві сесії можуть правити ті самі файли, і приєднає лише після другого натискання *Черга для Claude*. Надійніше — окрема папка або git worktree.
- **Спливні повідомлення.** Коли інша сесія просить дозволу або ставить запитання, спливне повідомлення у твоїй панелі Arcade скаже *Сесія «api» чекає дозволу* або *…чекає відповіді на запитання* — без звуку й системного сповіщення. Вимкнути його або ввімкнути спливне повідомлення про закінчений хід (типово вимкнене) — у *Налаштування → Сповіщення*.
- **Сховати зайву.** × біля іншої сесії прибирає її зі списку разом зі спливними повідомленнями, доки її не повернуть із *Прихованих сесій* унизу; прихована сесія, що чекає дозволу чи відповіді, там так і підписана. Приховані пам’ятаються в усіх сесіях.
- **Лишається на цьому комп’ютері.** Кожна сесія тримає маленький файл у `~/.claude/arcade/agents` — її папка, стан і картка, запитання чи запит дозволу, на який вона чекає, а ще її контекст, витрати й вікна лімітів для [Лімітів](#ліміти); відповідь з *Агентів* іде сесії маленьким файлом поруч. На сайт Arcade нічого не йде.

## Ліміти

Це в розділі *Робота* меню. Цифри — від самого Claude Code, ті самі, що в рядку стану: Arcade сам нічого не рахує.

- **Вікна лімітів.** 5 годин, тиждень і ліміт витрат — відсоток, смужка й час скидання: *скинеться о 14:30 (через 1 год 20 хв)*. Смужка синя, з 80% — жовта, а коли ліміт закінчився — червона. Вікна лімітів — в облікового запису, спільні для всіх його сесій, тож на екрані — найсвіжіший замір з усіх сесій на цьому комп’ютері й скільки хвилин тому його зроблено.
- **Коли вікон немає.** До першої відповіді Claude екран так і скаже: *З’явиться після першої відповіді Claude.* З ключем API або через шлюз вікон немає зовсім — лише контекст і витрати: вікна на 5 годин і на тиждень бувають у підписок Claude (Pro, Max, Team, Enterprise).
- **Ця сесія та інші.** Заповнення контексту — у відсотках і токенах — і витрати від початку сесії; нижче — контекст і витрати інших сесій на цьому комп’ютері. Ті самі цифри видно в їхніх картках в [Агентах](#агенти).
- **Черга після скидання.** Якщо хід Claude обірвався посеред [черги дошки](#блокнот-і-дошки-проєктів), а Claude Code показує вікно на 100%, черга зупиняється й пише, коли ліміт скинеться. *Продовжити чергу після скидання о 14:31* продовжить її з тієї ж картки за хвилину після скидання; поки вона чекає — *Черга «Реліз» продовжиться о 14:31.* і *Не продовжувати*. Дошку можна позначити заздалегідь — тоді її черга продовжиться сама, без кнопки.
- **Лише поки Claude Code відкритий.** Продовжити чергу може лише відкрита сесія на комп’ютері, який не спить. Якщо Claude Code було закрито або комп’ютер спав, *Ліміти* так і скажуть: *Черга «Реліз» не продовжилася після скидання ліміту: Claude Code було закрито або комп’ютер спав.*; якщо закрили сесію, яка чекала, — *…не запустилася після скидання ліміту: сесію було закрито.* × прибирає це повідомлення.
- **Спливне повідомлення на 80 і 90%.** Коли вікно доходить до 80%, а потім до 90%, у панелі Arcade з’являється спливне повідомлення — про кожен поріг один раз в усіх сесіях. Вимкнути його можна в *Налаштування → Сповіщення*.
- **Який Claude Code.** Ліміти плагінам повідомляє не кожна версія Claude Code — перевірено на 2.1.302 і 2.1.316. Якщо твоя їх не повідомляє, екран так і скаже, а решта Arcade працює як звичайно.

## Для команд

Невелика команда може вести свої завдання в Arcade: одна спільна дошка, а хто бере картку, віддає її своєму Claude.

1. Кожен встановлює Arcade (Claude Code 2.1.275 або новіший) — див. [Встановлення](#встановлення).
2. `/arcade` → **Спілкування** → **Увійти через GitHub**: сторінка GitHub відкривається в браузері — підтверди вхід там, потім натисни *Sign in* на сторінці Arcade (код на ній має збігатися з кодом у панелі). Якщо не виходить — *Увійти за кодом*.
3. Візьми @нік — ім’я з GitHub одним натисканням або своє.
4. Додай колег у друзі за точним @ніком; вони приймають запит у себе.
5. **Робота** → створи дошку → познач колег → **Поділитися**.
6. Потрібні лише дошки й чати? Під час першого запуску Arcade залиш тільки **Робота** і **Спілкування**. Потім у **Налаштування → Сповіщення** натискай **Рядок «зіграти?»**, доки не з’явиться *вимкнено*: поки агент працює, над полем вводу нічого не з’являтиметься.

Далі так: відкрий дошку, вибери картку, **Віддати Claude**. Якщо Claude вільний, картка одразу йде до нього; якщо зайнятий — чекає в полі вводу, доки ти її не надішлеш. Claude позначає зроблене й дописує підсумок на картку, і всі на дошці бачать це за лічені секунди — і хто яку картку взяв. Дай кожній картці термін — і він з’явиться в твоєму календарі. Наприкінці дня *Підсумки дня* → *Надіслати в чат* надішлють твій стендап у чат команди. Чати — у розділі **Спілкування**.

Сам працюєш у кількох сесіях Claude Code? Натисни *Черга для Claude* на тій самій дошці в кожній: вільна сесія візьме наступну картку, а **Робота** → **Агенти** покаже, що робить кожна.

Варто знати: спільні дошки й чати зберігаються на сайті Arcade і не шифруються, тож не тримай там паролів і ключів. Arcade дізнається лише ім’я та зображення твого профілю GitHub. Власних спільних дошок — до 3, на дошці — до 20 людей і 200 карток. *Видалити акаунт* (натиснути двічі) — сайт забуває тебе й твої налаштування.

## Акаунт, друзі й чати

Вхід необов’язковий — без нього все інше працює як раніше.

- **Увійти через GitHub** (у розділі *Спілкування*): сторінка входу GitHub відкривається у твоєму звичайному браузері — підтверди вхід там, потім натисни *Sign in* на сторінці Arcade; код на ній має збігатися з кодом у панелі. Якщо через браузер не виходить — *Увійти за кодом*: Arcade показує код, ти вводиш його на сторінці GitHub. Arcade дізнається лише ім’я та зображення твого профілю GitHub — без пошти й доступу до репозиторіїв.
- **Синхронізація.** Мова, клавіші, сповіщення, розмір панелі, що робити з грою за сигналом агента, налаштування браузера в Desktop, твої теми, канали Twitch, обране, згорнуті й приховані розділи й рекорд Flappy Arcade стають однаковими на всіх твоїх комп’ютерах. Свої ігри, браузер і режим графіки — окремо на кожному комп’ютері.
- **@нік.** Візьми ім’я з GitHub одним натисканням або придумай своє: від 4 до 32 знаків — латинські літери, цифри та `_`. Змінювати можна до 5 разів на день.
- **Друзі.** Додай друга за точним @ніком: запит приймають на тому боці, і ви з’являєтеся у списках одне одного. Підказок під час введення немає, тож ніхто не може переглядати, хто є в Arcade. Відхилення й видалення відбуваються мовчки.
- **У мережі та запрошення в гру.** Поки меню Arcade відкрите, друзі бачать тебе *у мережі*, а ти — їх; щоб не показуватися, вимкни *Показувати друзям, що я в мережі* на екрані *Друзі*. *Запросити* біля друга пропонує мережеві ігри: настільна відкриває кімнату на двох, гра з Doom — своє лобі. Гра одразу відкривається в тебе, а в друга — сповіщення й *Прийняти* вгорі меню; запрошення діє 10 хвилин. Запрошувати можна там, де мережеві ігри відкриваються в браузері, — у вбудованому в Desktop або у вікні браузера.
- **Чати.** Віч-на-віч із другом, групи друзів або група з усіма друзями одним натисканням. Пиши прямо в панелі Arcade або відкрий сторінку чатів на сайті. Своє повідомлення можна змінити або видалити з меню ⋮ поруч із ним, а на сайті — ще й правою кнопкою. Повідомлення зберігаються на сайті Arcade і не шифруються — не пиши туди паролі чи ключі.

## Що плагін робить на твоєму комп’ютері

Arcade працює всередині Claude Code з тими правами, які Claude Code дає плагінам. Увесь його код — у цьому репозиторії, а `claude plugin validate ./mod` перелічує кожну подію, на яку він підписаний, і кожен виклик. Коротко:

- **Інструменти агента.** Arcade бачить, коли інструмент починається й закінчується і коли агент просить дозволу, — так він знає, коли показати банер. Виклики інструментів агента він ніколи не змінює й не блокує. Сам він дозволяє лише три види викликів і лише там, де Claude Code інакше спитав би тебе: `mcp__arcade__notes`, який змінює лише блокнот і нічого не видаляє; `mcp__arcade__calendar`, який змінює лише календар; та відкриття гри у вбудованому браузері Desktop після твого натискання в панелі. Твої правила дозволу й заборони діють як є.
- **Зупинка агента.** Лише в Claude Desktop, коли ти відкриваєш щось у вбудованому браузері, поки агент працює: Desktop не дає плагіну відкрити браузер самому. Arcade чекає, доки закінчиться поточний інструмент (через 10 секунд обриває його, але чекає, поки на екрані запит дозволу), зупиняє агента й просить Claude відкрити сторінку та повернутися до роботи. Щоб такого не було, обери вікно браузера в *Налаштування → Де відкривати ігри*.
- **Твоя розмова.** Для тем Haiku у твоїй власній сесії отримує кінець розмови — кілька тисяч символів; це йде у твоє використання Claude. Сайт Arcade розмови не бачить. У поле введення Arcade пише чи надсилає його лише на твоє прохання — наприклад, *Віддати Claude* у блокноті або наступну картку черги, яку ти запустив кнопкою *Черга для Claude*, — або щоб відкрити сторінку, як описано вище.
- **Ліміти.** Після кожного ходу й раз на пів хвилини Arcade питає в Claude Code його власний замір лімітів, контексту й витрат — те, що показує рядок стану. Це нічого не коштує й не йде у твоє використання Claude.
- **Програми.** Твій браузер для вікна Arcade (у Windows — з окремим профілем у `%LOCALAPPDATA%\claude-arcade`); сповіщення, зокрема нагадування календаря, — PowerShell у Windows, `osascript` у macOS, `notify-send` у Linux; перевірка, які браузери встановлено (Windows) або яка це ОС (`uname`).
- **Файли.** Записує лише ROM, які ти додаєш через `/arcade-add`, — у `~/.claude/arcade/roms`, і маленьку позначку кожної сесії для *Агентів* і *Лімітів* з відповідями, надісланими звідти, — у `~/.claude/arcade/agents`; читає лише названий тобою файл, ці копії, ці позначки та власні файли. Налаштування, блокнот, календар і обране лежать у сховищі плагінів Claude Code.
- **Змінні середовища.** Читає `HOME` або `USERPROFILE`, `LANG`, `LC_ALL`, `LC_MESSAGES`, `LOCALAPPDATA` та `OS`; жодної не змінює.
- **Мережа.** Сам плагін звертається лише до сайту Arcade (`agent-arcade.fefaodessa.workers.dev`), до RSS-стрічок каналів YouTube і до стрічок блогів і подкастів, які показує. Картинки в панелі Desktop, як-от аватарки Twitch, вантажаться просто з цих сервісів. Ігри, книжки й відео завантажує сторінка, відкрита в браузері.

## Підтримати проєкт

Arcade безкоштовний. Якщо з ним чекати веселіше, можна пригостити проєкт кавою — цілком добровільно: **[ko-fi.com/agentarcade](https://ko-fi.com/agentarcade)**. Те саме посилання є внизу меню `/arcade` (*☕ Підтримати проєкт*) і у вікні Arcade. Ніщо в Arcade від цього не залежить, і гру воно ніколи не перериває.

## Відгуки

Щось зламалося? Найшвидше — прямо в Arcade: **Ще → 🐞 Повідомити про помилку**. Опиши, що сталося, і звіт піде просто авторові Arcade разом із версією, середовищем, мовою та ОС.

Також можна відкрити [issue](https://github.com/ArbakovMaxim/agent-arcade/issues) — для помилок та ідей. Вкажи, будь ласка, ОС, середовище Claude Code (термінал, VS Code чи Desktop) і гру.

Pull request-и вітаються. Надсилаючи його, ти погоджуєшся, що твій внесок ліцензується під AGPL-3.0 і що автор може також пропонувати Arcade на інших умовах (наприклад, за комерційною ліцензією).

## Розробникам

```
mod/     плагін Claude Code (хуки, інтерфейс панелі, тести)
site/    сайт на Cloudflare Workers: каталог, вікно Arcade, мережеві кімнати, акаунти, друзі, чати, звіти про помилки
tools/   допоміжні збирачі: переклади, heretic-wasm
.github/ GitHub Actions, що збирають doom-wasm, heretic-wasm, OpenTTD і ScummVM для браузера
```

- Запуск плагіна з репозиторію: `claude --plugin-dir ./mod`
- Тести плагіна: `claude plugin validate ./mod`, потім `claude plugin test` у `mod/`
- Тести сайту: `npm test` у `site/`; збірка: `node build.mjs`; деплой відбувається автоматично з `main` через Cloudflare Workers Builds.
- Робота йде в `main`, pull request'и — туди ж. Гілка за замовчуванням `plugin` — копія `main` без `site/`, яку GitHub Action оновлює на кожен пуш: маркетплейс плагінів завантажує її, а не весь репозиторій.
- Переклади: `node tools/i18n/collect.mjs`, потім `node tools/i18n/check.mjs` — див. [tools/i18n/README.md](tools/i18n/README.md).

Докладна документація (російською): [mod/docs/README.ru.md](mod/docs/README.ru.md) — плагін, [site/README.md](https://github.com/ArbakovMaxim/agent-arcade/tree/main/site/README.md) — сайт, додавання ігор і гра по мережі.
