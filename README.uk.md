# Arcade — грай, читай, слухай і дивись, поки агент Claude Code працює

[English](README.md) · [Русский](README.ru.md) · **Українська** · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [한국어](README.ko.md)

> **Альфа (0.26).** Arcade працює й щодня в ділі, але це рання версія: щось може зламатися, а налаштування чи каталог — змінитися між оновленнями. Повідомлення про помилки дуже вітаються — див. [Відгуки](#відгуки).

Arcade — плагін для [Claude Code](https://claude.com/claude-code), який заповнює очікування, поки агент працює. Коли агент зайнятий довше за 10 секунд, над полем вводу з’являється невелике *«зіграти?»*. Зіграй у гру — NES, Sega, PlayStation, Doom, шахи та інше, — почитай книгу, послухай аудіокнигу чи подкаст або подивись відео на тему роботи агента. Arcade повідомить тієї ж миті, коли агент закінчить або попросить дозволу, — нічого не пропустиш.

Усе в каталозі безкоштовне: ігри мають відкриті ліцензії, книги й аудіокниги — у суспільному надбанні. Можна також грати по мережі з іншими людьми, які теж чекають на своїх агентів, і листуватися з друзями.

![«зіграти?» над полем вводу Claude Code після 11 секунд роботи агента](docs/images/prompt.png)

## Можливості

- **З’являється сам.** Після 10 секунд роботи агента Arcade пропонує гру над полем вводу; фокус не забирає, доки ти про це не попросиш.
- **Знає, що робить агент.** Коли агент закінчив або просить дозволу, над грою з’являється банер — грай далі, постав паузу або одразу повертайся до агента (поведінку обираєш у налаштуваннях). У Claude Desktop Arcade може ще й закрити вкладку, де ти дивишся, — і перед тобою знову розмова.
- **Одне меню, шість розділів.** *Грати*, *Читати й слухати*, *Дивитися*, *Спілкування*, *Робота* і *Ще* — згорни ті, що не потрібні. Угорі: *Продовжити* останню гру, *Знайти* та *Обране*.
- **61 безкоштовна гра**: NES (Dendy), Sega Mega Drive, Master System, PlayStation і вкладка *Ігри* з аркадами, шутерами, перегонами, стратегіями, квестами й настільними іграми.
- **Читай і слухай.** Класика й аудіокниги LibriVox 30 мовами — просто з Project Gutenberg, Wikisource і LibriVox, а ще свіжі статті й випуски подкастів на тему роботи агента.
- **Дивись.** Свіжі відео YouTube на тему роботи агента, Twitch: твої канали та трансляції про програмування, технології, науку й ретроігри, і TikTok: стрічка *Для тебе* та пошук на самому сайті TikTok, куди ти входиш сам.
- **NES і Flappy Arcade прямо в Claude Code** — у терміналі, VS Code і Claude Desktop. Решта відкривається у вікні браузера — у Claude Desktop за замовчуванням у вбудованому браузері Claude (шутери все одно відкриваються у вікні браузера: вбудований браузер не захоплює мишу).
- **Гра по мережі.** Ігри на двох для приставок по мережі, Doom — deathmatch і кооператив, шахи, го, шашки й реверсі проти людей або комп’ютера.
- **«Хто чекає онлайн».** Arcade показує в Claude Code, коли хтось чекає на партнера, з кнопкою *Приєднатися*.
- **Друзі й чати.** Необов’язковий вхід через GitHub робить налаштування однаковими на всіх твоїх комп’ютерах і дає @нік; додавай друзів за точним ніком, дивись, хто в мережі, запрошуй зіграти й листуйся віч-на-віч або в групах.
- **Блокнот і дошки проєктів.** Сторінки, підсторінки й чек-листи, які веде й Claude; сторінку можна надіслати в Notion чи інший застосунок або забрати звідти через конектори Claude; надиктуй у поле введення Claude й перенеси текст на сторінку. Дошки з колонками й картками — поділися дошкою з друзями, і всі працюють на одній.
- **Пошук і обране.** Один пошук по іграх і каналах Twitch, згрупований за розділами й жанрами; познач гру зірочкою ☆, щоб вона була в *★ Обране*.
- **Свої ігри.** Додавай ROM, які в тебе є; вони залишаються на твоєму комп’ютері.
- **13 мов інтерфейсу:** English, Русский, Українська, Español, Français, Deutsch, Português, Italiano, Polski, Türkçe, 日本語, 中文, 한국어 — за мовою системи чи браузера, за замовчуванням англійська.

## Встановлення

Потрібен **Claude Code 2.1.275 або новіший**.

У терміналі — дві команди: додай маркетплейс Arcade (цей репозиторій), потім установи з нього плагін:

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

Або всередині сесії Claude Code:

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

Плагін встановлюється для всіх сесій і застосунків. У розширенні VS Code немає команди `/plugin` — встанови з термінала, і розширення підхопить плагін у новій розмові.

**Оновлення:**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

Потім перезапусти Claude Code. Маркетплейс завантажує лише плагін — кілька МіБ, без сайту, — тож оновлення займає секунди. Якщо Arcade вже встановлено, нічого робити не треба: маркетплейс перемкнеться сам під час наступного оновлення.

Якщо `/plugin update` пише *already at the latest version*, а нова версія Arcade вже вийшла, — маркетплейс не оновився. Причину покаже `claude plugin marketplace update agent-arcade` у терміналі. Якщо там *timed out*, дай клонуванню 10 хвилин:

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

У PowerShell: `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade`. Потім знову `/plugin update arcade@agent-arcade`.

**Видалення:** `/plugin uninstall arcade@agent-arcade`

## Як користуватися

- **`/arcade`** відкриває меню будь-коли.
- Коли агент працює довше за 10 секунд, над полем вводу з’являється *«зіграти?»*: **`1`** — грати тут, у панелі; **`2`** — у вікні браузера (де можна); **`3`** — не зараз.
- Стрілки або Tab — вибір, Enter — відкрити; миша теж працює. Керування показано під кожною грою.
- Коли агент закінчив або чекає на дозвіл, над грою з’являється банер: **До агента** або **Грати далі**.

### Меню

| Розділ | Що всередині |
|---|---|
| *(угорі)* | **▶ Продовжити** останню гру, **🔍 Знайти**, **★ Обране** |
| **Грати** | NES, Sega, Master System, PlayStation, Ігри; *Приєднатися*, коли хтось чекає онлайн; **Мої ігри** |
| **Читати й слухати** | Книги, Аудіокниги, Статті, Подкасти |
| **Дивитися** | YouTube, Twitch, TikTok |
| **Спілкування** | Друзі, Чати, **Увійти через GitHub** (або **Акаунт** після входу) |
| **Робота** | Блокнот, Дошка проєктів |
| **Ще** | Вікно Arcade, Налаштування, 🌐 мова, 🐞 Повідомити про помилку, ☕ Підтримати проєкт |

Натисни заголовок розділу, щоб згорнути чи розгорнути його. Згорнутий розділ показує `▸` і скільки в ньому плиток, а *Спілкування* — ще й нові повідомлення 💬 і запити в друзі 👥. Arcade пам’ятає, які розділи згорнуто. Після входу в шапці меню видно твій @нік із тими самими лічильниками.

**Пошук** працює від двох літер і шукає за назвою або жанром, без урахування регістру й діакритики. Результати згруповано за розділами й жанрами, як-от *Ігри · Шутери*. Зірочка ☆ біля гри додає її в **★ Обране** (до 100), розкладене за розділами й жанрами, найновіші — першими. У книг і аудіокниг — свій пошук, за назвою або автором.

### Де що відкривається

| | NES (Dendy), Flappy Arcade | Sega, Master System, PlayStation, інші Ігри; книги, аудіокниги, статті, подкасти, відео |
|---|---|---|
| **Термінал** | у панелі (піксельна графіка, де термінал її підтримує, інакше — текстові блоки) | вікно браузера |
| **VS Code** | у панелі | вікно браузера |
| **Claude Desktop** | у панелі | вбудований браузер Claude або вікно браузера (вибір у налаштуваннях); шутери — завжди вікно браузера |

Вікно браузера — це окреме вікно Arcade (у браузері за замовчуванням або в тому, який обереш у налаштуваннях), а не вкладка серед твоїх звичайних. Чати працюють прямо в панелі — у терміналі й у Desktop; *Відкрити на сторінці* відкриває їх на сайті так само. Блокнот і дошки проєктів — у панелі. TikTok у Desktop відкривається у вбудованому браузері Claude, а деінде — у браузері за замовчуванням, де ти, найімовірніше, уже ввійшов.

## Гра по мережі

- **Приставки.** Ігри на двох для NES, Sega, Master System і PlayStation мають кнопку **Онлайн**: створи кімнату або приєднайся до чужої. Натискання синхронізуються кадр за кадром через сервер Arcade.
- **Doom.** **FreeDM** і **BlasphDM** — лобі deathmatch із 5-хвилинними раундами до чотирьох гравців; у **Freedoom** і **Blasphemer** — кооператив через **Онлайн**. Новачки чекають наступного раунду — рушій не дає приєднатися до матчу, що вже йде.
- **Настільні ігри.** *Знайти суперника*, *Запросити друга* за посиланням або *Проти комп’ютера*. Партія зберігається на сервері: зроби хід, повернися до агента, відкрий посилання пізніше — дошка там, де її залишено. Якщо ти ввійшов з @ніком, суперник бачить його поруч із твоїм кольором.
- **Хто чекає.** Раз на хвилину Arcade перевіряє, чи хтось чекає на партнера, і показує це в Claude Code — наприклад, *«зіграти? Онлайн чекають: FreeDM (1)»* — з кнопкою **Приєднатися** в меню.

## Акаунт, друзі й чати

Вхід необов’язковий — без нього все інше працює як раніше.

- **Увійти через GitHub** (у розділі *Спілкування*): Arcade показує код, ти вводиш його на сторінці GitHub у своєму звичайному браузері. Arcade дізнається лише ім’я та зображення твого профілю GitHub — без пошти й доступу до репозиторіїв.
- **Синхронізація.** Мова, клавіші, сповіщення, розмір панелі, що робити з грою за сигналом агента, налаштування браузера в Desktop, твої теми, канали Twitch, обране, згорнуті розділи й рекорд Flappy Arcade стають однаковими на всіх твоїх комп’ютерах. Свої ігри, браузер і режим графіки — окремо на кожному комп’ютері.
- **@нік.** Візьми ім’я з GitHub одним натисканням або придумай своє: від 4 до 32 знаків — латинські літери, цифри та `_`. Змінювати можна до 5 разів на день.
- **Друзі.** Додай друга за точним @ніком: запит приймають на тому боці, і ви з’являєтеся у списках одне одного. Підказок під час введення немає, тож ніхто не може переглядати, хто є в Arcade. Відхилення й видалення відбуваються мовчки.
- **У мережі та запрошення в гру.** Поки меню Arcade відкрите, друзі бачать тебе *у мережі*, а ти — їх; щоб не показуватися, вимкни *Показувати друзям, що я в мережі* на екрані *Друзі*. *Запросити* біля друга пропонує мережеві ігри: настільна відкриває кімнату на двох, гра з Doom — своє лобі. Гра одразу відкривається в тебе, а в друга — сповіщення й *Прийняти* вгорі меню; запрошення діє 10 хвилин. Запрошувати можна там, де мережеві ігри відкриваються в браузері, — у вбудованому в Desktop або у вікні браузера.
- **Чати.** Віч-на-віч із другом, групи друзів або група з усіма друзями одним натисканням. Пиши прямо в панелі Arcade або відкрий сторінку чатів на сайті. Повідомлення зберігаються на сайті Arcade і не шифруються — не пиши туди паролі чи ключі.
- **Аватарки й сповіщення про повідомлення.** Обери одну з 24 готових аватарок в *Акаунті* — чати її лише показують; без неї — перша літера твого @ніка. Картинку групи обирає її власник із тих самих 24. Картинку профілю GitHub іншим не показуємо. Коли друг пише, унизу ліворуч поверх усіх вікон спливає картка (Windows) або приходить системне сповіщення (macOS, Linux); клік по картці відкриває цей чат.
- **Вийти** зупиняє синхронізацію на цьому комп’ютері; **Видалити акаунт** (натиснути двічі) — сайт забуває тебе й твої налаштування.

## Блокнот і дошки проєктів

Обидва — у розділі *Робота* меню.

- **Блокнот.** Сторінки й підсторінки; рядок, що починається з `# `, — заголовок, з `- ` — пункт, з `- [ ] ` — пункт чек-листа, який відмічається натисканням. Зберігається на цьому комп’ютері — до 200 сторінок, 20 000 знаків на сторінці.
- **Claude теж його веде.** *Віддати Claude* передає сторінку Claude, або просто попроси Claude записати щось в Arcade. Claude користується інструментом `mcp__arcade__notes`, який змінює лише блокнот і нічого не видаляє. Не сподобалася правка Claude — *Повернути текст до правки Claude*.
- **Notion та інші застосунки** — через конектори Claude, тож Arcade не потрібні ключі чи паролі: *Надіслати в Notion*, *В інший застосунок*, *Забрати з Notion або іншого застосунку*. Пов’язану сторінку можна оновити в застосунку або знову забрати звідти.
- **Голосом.** Надиктуй у поле введення Claude системним диктуванням (Win+H у Windows, двічі Fn у macOS) і натисни *Взяти з поля введення Claude* — текст перейде в кінець сторінки.
- **Дошка проєктів.** Колонки — *Зробити*, *В роботі*, *Готово* або свої, до 8, — і картки; картка — це сторінка блокнота з текстом і чек-листом. Натисни на картку, щоб вибрати її й переносити стрілками, ще раз — щоб відкрити. Claude теж веде дошки: *Віддати Claude* або попроси його розкласти завдання по дошці в Arcade.
- **Спільні дошки.** Якщо ти ввійшов з @ніком, познач друзів і натисни *Поділитися*: картки, колонки й назва в усіх однакові, а зміни доходять за лічені секунди. Власник запрошує ще друзів, прибирає учасників і видаляє дошку з сайту; вийти може будь-хто; хай що станеться, у кожного лишається своя копія. Власних спільних дошок — до 3, на дошці — до 20 людей і 200 карток.

## Свої ігри

- **`/arcade-add <файл>`** додає ROM для NES, Mega Drive або Master System (до 4 МБ). Плагін зберігає копію в `~/.claude/arcade` і нікуди її не завантажує.
- **Диски PlayStation і WAD для Doom** (наприклад, твій `doom.wad`) — у вікні Arcade: **Відкрити свій файл**. Вони залишаються лише в цьому браузері.

Додавай тільки файли, на які маєш права.

## Налаштування

Відкрий **Налаштування** в розділі *Ще* меню `/arcade`:

- **Мова** — одна з 13 (також прямо в меню: 🌐).
- **Де відкривати ігри** — тут у панелі, у вікні браузера або в конкретному браузері; у Claude Desktop — у вбудованому браузері Claude або у вікні браузера.
- **Графіка** (термінал) — пікселі в терміналах, що показують зображення (kitty, Ghostty, Rio), текстові блоки — всюди.
- **Розмір панелі** — звичайна або на всю ширину.
- **Коли агент закінчить** — банер і грати далі, пауза з банером або одразу до агента.
- **Коли агент просить дозволу** — ті самі три варіанти.
- **Коли відкривається браузер** (Claude Desktop) — закривати меню Arcade, щоб браузер був на всю висоту, або залишати меню над ним.
- **Агент закінчив, поки дивишся** (Claude Desktop) — закрити вкладку, яку Arcade відкрив для відео, трансляції, TikTok, статті чи випуску, щоб перед тобою знову був чат із Claude, або лише повідомити.
- **Сповіщення під час гри у вікні.**
- **Сповіщення про повідомлення** — картка внизу ліворуч, коли друг пише в чат (у macOS і Linux — системне сповіщення).
- **Перевірка й перепризначення клавіш** (термінал).

## Приватність

- Без реклами, аналітики й стеження. З ігор, що мали аналітику, її прибрано (див. `NOTICE` кожної гри).
- Твої ROM, WAD, книги й аудіофайли ніколи не залишають твій комп’ютер чи браузер.
- Списки книг і аудіокниг та книги Project Gutenberg ідуть через сайт Arcade: він бере їх у Project Gutenberg, Wikisource і archive.org і тримає лише в кеші Cloudflare — списки шість годин, книгу тиждень. Сторінки Wikisource і записи LibriVox вікно бере просто з цих сайтів.
- Гра по мережі йде через сервер Arcade на Cloudflare: повідомлення пересилаються між гравцями в кімнаті й не зберігаються — крім ходів настільних ігор, які зберігаються, щоб можна було повернутися; партію, яку не чіпали місяць, видаляють.
- Теми пропонує Haiku у твоїй власній сесії Claude Code; сайт Arcade ніколи не бачить твоєї розмови — лише короткий англійський пошуковий запит, коли використовується *Своя тема*. Адреса статті йде після `#`, тож вона ніколи не доходить до сервера Arcade.
- Після входу сайт зберігає синхронізовані налаштування, обране, @нік, друзів, чати й спільні дошки, а запрошення в гру — 10 хвилин. Хто в мережі, він тримає тільки в пам’яті, півтори хвилини. Ключ сесії йде тільки на сайт Arcade.
- Блокнот залишається на твоєму комп’ютері. Спільні дошки зберігаються на сайті Arcade і не шифруються, як і чати. У Notion чи інший застосунок сторінки йдуть, лише коли ти попросиш, через твої власні конектори Claude.
- Звіт про помилку містить твій текст, версію Arcade, де вона відкрита, мову інтерфейсу та ОС — і нічого більше; без входу він надходить без підпису, а сайт не зберігає адрес.
- Деякі ігри виходять в інтернет лише на твоє прохання — наприклад, необов’язкове опитування OpenTTD і його кнопка *Online Content*.

## Розробникам

```
mod/     плагін Claude Code (хуки, інтерфейс панелі, тести)
site/    сайт на Cloudflare Workers: каталог, вікно Arcade, мережеві кімнати, акаунти, друзі, чати, звіти про помилки
tools/   допоміжні збирачі: переклади, heretic-wasm
.github/ GitHub Actions, що збирають doom-wasm, heretic-wasm, OpenTTD і ScummVM для браузера
```

- Запуск плагіна з репозиторію: `claude --plugin-dir ./mod`
- Тести плагіна: `claude plugin validate ./mod`, потім `claude plugin test` у `mod/`
- Тести сайту: `npm test` у `site/`; збірка: `node build.mjs`; деплой відбувається автоматично з `main` через Cloudflare Workers Builds.
- Робота йде в `main`, pull request'и — туди ж. Гілка за замовчуванням `plugin` — копія `main` без `site/`, яку GitHub Action оновлює на кожен пуш: маркетплейс плагінів завантажує її, а не весь репозиторій.
- Переклади: `node tools/i18n/collect.mjs`, потім `node tools/i18n/check.mjs` — див. [tools/i18n/README.md](tools/i18n/README.md).

Докладна документація (російською): [mod/README.md](mod/README.md) — плагін, [site/README.md](https://github.com/ArbakovMaxim/agent-arcade/tree/main/site/README.md) — сайт, додавання ігор і гра по мережі.
