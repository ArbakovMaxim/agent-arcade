Собрано в GitHub Actions официальным способом из dists/emscripten/build.sh — .github/workflows/scummvm-wasm.yml
в репозитории Arcade (https://github.com/ArbakovMaxim/agent-arcade):
  build.sh configure make dist --disable-all-engines --enable-engine=sky,queen,lure,parallaction --disable-seq-midi --disable-timidity --enable-freetype2 --enable-png
  build.sh games add-games
Эти два ключа вшивают в scummvm.wasm библиотеки из портов Emscripten 3.1.51:
  --enable-freetype2 — FreeType (https://github.com/emscripten-ports/FreeType, тег version_1), © The FreeType Project,
    по выбору GPL или FTL (FreeType-LICENSE.TXT, FreeType-FTL.TXT); без него нет шрифтов меню (data/fonts.dat) и современных тем;
  --enable-png — libpng 1.6.39 (libpng-LICENSE.txt) и zlib 1.2.13 (zlib-LICENSE.txt); без него лаунчер в большом окне
    (сетка игр с картинками) падает.
add-games нашёл все четыре игры, но не смог записать scummvm.ini (ошибка в его node-скрипте) —
scummvm.ini с этими четырьмя играми записан шагом workflow.
Код ScummVM не менялся.

ИЗМЕНЕНО для Arcade: scummvm.html подключает BrowserFS 2.0.0 (MIT, BrowserFS-LICENSE.md) из browserfs.min.js рядом,
а не с cdnjs.cloudflare.com — это тот же файл, его sha512 совпадает с integrity в исходной странице.
