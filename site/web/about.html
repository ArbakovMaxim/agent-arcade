Arcade for Claude Code

Task boards, notes and team chats inside Claude Code

A free, open-source plugin. Put a task on a board, press Give to Claude, and Claude ticks off the checklist and writes the result back on the card.

Install View on GitHub

What's inside

Task boards next to the agent

Every card is a page with a checklist. Press Give to Claude: if Claude is free, it starts right away; if it's busy, the card waits in the prompt box until you send it. Claude ticks off each item and writes the result on the card.

A notebook Claude keeps with you

Claude reads and edits it with you, and every open session sees the same notebook. Its tool deletes nothing, and you can restore the text from before Claude's last edit.

Shared boards and team chats

Optional GitHub sign-in: shared boards for up to 20 people, one-on-one and group chats. You can edit and delete your own messages.

While Claude works

After 10 seconds of agent work, a small “play?” line appears: play an NES game or read a book, and a banner calls you back the moment Claude finishes. Don't need it? Turn it off; boards, notes and chats stay.

Install

In a terminal:

claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade

Then restart Claude Code and type /arcade.

Works in the terminal, VS Code and Claude Desktop.
