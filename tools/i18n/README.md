# Переводы Arcade

Интерфейс написан по-русски, английский перевод — в `mod/hooks/i18n.js` и `site/web/i18n.js`. Остальные 11 языков
(uk, es, fr, de, pt, it, pl, tr, ja, zh, ko) переводятся **с английского**:

- мод — `mod/hooks/locales/<язык>.js`, окно — `site/web/locales/<язык>.json`;
- `exact` — английская фраза → перевод;
- `templates` — английский шаблон с местами `{0}`, `{1}` → перевод с теми же местами (их можно переставлять). Что
  подставлено в место, переводится отдельно (например, `11 s` — по шаблону `{0} s`);
- форма числа: `{0#one=# Spiel;other=# Spiele}` — категории `Intl.PluralRules` языка (`one`, `few`, `many`, `other`…),
  `other` обязательна, `#` — само число. Для японского, китайского, корейского достаточно `other`;
- `words` — пары для подсказок клавиш («move» → «Bewegung»): заменяются внутри строки.

Не переводятся: названия игр и книг, имена, «Arcade», названия приставок (NES, Sega, PlayStation…), команды
(`/arcade`, `/arcade-add`), адреса и пути. Клавиши — как принято на языке («Space» → «Leertaste», «Espacio», «空格键»;
Enter, Esc, Shift, Ctrl обычно остаются как есть).

Фразы, которые код собирает сам и которых нет среди строк кода (например «a Chrome window», «the default browser»),
добавляй в `tools/i18n/templates.json`: шаблоны — в `mod` и `site`, готовые фразы — в `modExact` и `siteExact`.
`collect.mjs` их учтёт и не удалит.
Названия языков в меню — уже на самих языках.

Порядок работы:

1. `node tools/i18n/collect.mjs` — собирает английские фразы из кода и обновляет заготовки: новые фразы — пустыми,
   лишние убирает, готовые переводы не трогает. Запускать после любой правки интерфейса.
2. Заполнить пустые строки во всех 22 файлах.
3. `node tools/i18n/check.mjs` — должно закончиться строкой «переводы в порядке».
4. Тесты мода и сайта.
