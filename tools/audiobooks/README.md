# Аудиокниги · audiobooks

Аудиокниги каталога — записи [LibriVox](https://librivox.org) (общественное достояние). Звук не хранится у нас:
окно Arcade играет MP3 прямо с archive.org, где LibriVox их держит.

1. Найди книгу на librivox.org и возьми её номер: он есть в адресе API или в ссылке «Download» → «Book ID».
2. Впиши в `audiobooks.json`: `id` (латиница через дефис), `librivox` (номер), `title`, `author`, `lang`, `genre`
   (наши жанры: «роман», «сказки», «рассказы»…). Необязательно: `about`, `about_en`, `reader`, `year`.
3. `node tools/audiobooks/build.mjs` — главы, длительность и чтецы попадут в `site/content/audiobooks/index.json`.
4. Пересобери сайт: книга появится во вкладке «Аудиокниги» на полке своего языка (`lang`), внутри — в своём жанре.
   Полка языка создаётся сама: первая аудиокнига на новом языке — новая полка с названием языка на нём.

Своих аудиокниг здесь нет: их люди открывают в окне («Мои аудиокниги»), и файлы остаются в браузере.
