# Arcade — Claude Code 에이전트가 일하는 동안 플레이하고, 읽고, 듣고, 보세요

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md) · [中文](README.zh.md) · **한국어**

> **베타 버전(0.34).** 여기에 설명된 모든 기능이 작동하고 매일 사용되고 있습니다. 앞으로는 주로 세부 사항이 바뀝니다. 오류 신고는 언제든 환영합니다 — [피드백](#피드백)을 참고하세요.

Arcade는 에이전트가 일하는 동안의 기다림을 채워 주는 [Claude Code](https://claude.com/claude-code) 플러그인입니다. 에이전트가 10초 넘게 작업하면 프롬프트 위에 작은 *「플레이할까요?」* 가 나타납니다. NES, Sega, PlayStation, Doom, 체스 등으로 게임을 하거나, 책을 읽거나, 오디오북이나 팟캐스트를 듣거나, 에이전트가 작업 중인 주제의 영상을 볼 수 있습니다. 에이전트가 작업을 마치거나 권한을 요청하면 Arcade가 바로 알려 주므로 놓칠 일이 없습니다.

카탈로그의 모든 것은 무료입니다. 게임은 오픈 라이선스이고, 책과 오디오북은 퍼블릭 도메인입니다. 마찬가지로 에이전트를 기다리는 다른 사람들과 온라인으로 플레이하고, 친구와 채팅할 수도 있습니다.

## 기능

- **알아서 나타납니다.** 에이전트가 10초 동안 작업하면 Arcade가 프롬프트 위에서 게임을 제안합니다. 요청하지 않는 한 포커스를 가져가지 않습니다.
- **에이전트의 상황을 압니다.** 에이전트가 작업을 마치거나 권한을 요청하면 게임 위에 배너가 나타납니다. 계속 플레이하기, 일시 정지, 곧바로 에이전트로 돌아가기 중에서 설정으로 고를 수 있습니다. Claude Desktop에서는 보고 있던 탭을 닫아 대화를 다시 눈앞에 띄울 수도 있습니다.
- **메뉴 하나, 섹션 여섯 개.** *플레이*, *읽기·듣기*, *시청*, *소통*, *업무*, *더 보기* — 필요 없는 섹션은 접어 두세요. 맨 위에는 마지막 게임 *계속하기*, *검색*, *즐겨찾기*가 있습니다. Arcade를 처음 열 때 어떤 섹션을 표시할지 고를 수 있습니다.
- **무료 게임 61개.** NES(Dendy), Sega 메가 드라이브, 마스터 시스템, PlayStation, 그리고 아케이드·슈팅·레이싱·전략·어드벤처·보드게임을 모은 *게임* 탭.
- **읽기와 듣기.** 30개 언어의 고전과 LibriVox 오디오북(Project Gutenberg, Wikisource, LibriVox에서 바로), 에이전트 작업 주제에 맞춘 최신 아티클과 팟캐스트 에피소드.
- **시청.** 에이전트 작업 주제에 맞춘 최신 YouTube 영상과 Twitch: 내 채널, 그리고 코딩·기술·과학·레트로 게임 라이브 방송. TikTok도 있습니다: TikTok 공식 사이트의 *「추천」 피드*와 검색(로그인은 직접 합니다).
- **NES와 Flappy Arcade는 Claude Code 안에서 바로** — 터미널, VS Code, Claude Desktop 모두에서 실행됩니다. 나머지는 브라우저 창에서 열리며, Claude Desktop에서는 기본적으로 Claude 내장 브라우저에서 열립니다(슈팅 게임은 내장 브라우저가 마우스를 캡처할 수 없어 브라우저 창에서 열립니다).
- **온라인 플레이.** 네트워크로 즐기는 2인용 콘솔 게임, Doom 데스매치와 협동 플레이, 사람이나 컴퓨터를 상대로 하는 체스, 바둑, 체커, 리버시.
- **「온라인 대기 중인 사람」.** 누군가 상대를 기다리고 있으면 Arcade가 Claude Code에 *참가* 버튼과 함께 보여 줍니다.
- **친구와 채팅.** 선택 사항인 GitHub 로그인으로 모든 컴퓨터에서 같은 설정을 쓰고 @닉네임을 가질 수 있습니다. 정확한 닉네임으로 친구를 추가하고, 누가 온라인인지 보고, 게임에 초대하고, 1:1이나 그룹으로 채팅하세요.
- **노트와 프로젝트 보드.** Claude도 함께 쓰는 페이지, 하위 페이지, 체크리스트. Claude의 커넥터를 통해 페이지를 Notion이나 다른 앱으로 보내거나 거기서 가져올 수 있고, Claude 입력창에 받아쓴 텍스트를 페이지로 옮길 수도 있습니다. 열과 카드가 있는 보드는 친구와 공유하면 모두가 같은 보드에서 작업합니다.
- **검색과 즐겨찾기.** 게임과 Twitch 채널을 한 번에 검색하고, 결과는 섹션과 장르별로 묶입니다. ☆로 표시한 게임은 *★ 즐겨찾기*에 담깁니다.
- **내 게임.** 직접 소유한 ROM을 추가할 수 있습니다. ROM은 내 컴퓨터 밖으로 나가지 않습니다.
- **인터페이스 언어 13개:** English, Русский, Українська, Español, Français, Deutsch, Português, Italiano, Polski, Türkçe, 日本語, 中文, 한국어 — 시스템이나 브라우저 언어에 맞춰 선택되며, 기본값은 영어입니다.

## 설치

**Claude Code 2.1.275 이상**이 필요합니다.

터미널에서 명령 두 개를 실행합니다. Arcade 마켓플레이스(이 저장소)를 추가한 뒤, 거기서 플러그인을 설치합니다:

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

또는 Claude Code 세션 안에서:

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

플러그인은 모든 세션과 앱에 설치됩니다. VS Code 확장에는 `/plugin` 명령이 없으니 터미널에서 설치하세요. 확장은 새 대화에서 플러그인을 불러옵니다.

**업데이트:**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

그런 다음 Claude Code를 다시 시작합니다. 마켓플레이스는 플러그인만 내려받으므로(몇 MiB, 사이트 제외) 업데이트는 몇 초면 끝납니다. 이미 Arcade를 설치했다면 따로 할 일은 없습니다. 다음 업데이트 때 마켓플레이스가 알아서 전환됩니다.

`/plugin update`가 *already at the latest version*이라고 하는데 새 Arcade 버전이 나왔다면 마켓플레이스가 갱신되지 않은 것입니다. 터미널에서 `claude plugin marketplace update agent-arcade`를 실행하면 이유가 나옵니다. *timed out*이라고 나오면 클론에 10분을 줍니다:

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

PowerShell에서는 `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade`입니다. 그런 다음 `/plugin update arcade@agent-arcade`를 다시 실행합니다.

**제거:** `/plugin uninstall arcade@agent-arcade`

## 사용 방법

- **`/arcade`** 로 언제든 메뉴를 엽니다.
- 에이전트가 10초 넘게 작업하면 프롬프트 위에 *「플레이할까요?」* 가 나타납니다: **`1`** — 여기(패널)에서 플레이, **`2`** — 브라우저 창에서(가능한 경우), **`3`** — 지금은 안 함.
- 방향키나 Tab으로 고르고 Enter로 엽니다. 마우스도 됩니다. 조작법은 각 게임 아래에 표시됩니다.
- 에이전트가 작업을 마치거나 권한을 기다리면 게임 위에 배너가 나타납니다: **에이전트로 돌아가기** 또는 **계속 플레이**.

### 메뉴

| 섹션 | 내용 |
|---|---|
| *(맨 위)* | 마지막 게임 **▶ 계속하기**, **🔍 검색**, **★ 즐겨찾기** |
| **플레이** | NES, Sega, 마스터 시스템, PlayStation, 게임. 누군가 온라인에서 기다릴 때는 *참가*. **내 게임** |
| **읽기·듣기** | 책, 오디오북, 아티클, 팟캐스트 |
| **시청** | YouTube, Twitch, TikTok |
| **소통** | 친구, 채팅, **GitHub로 로그인**(로그인 후에는 **계정**) |
| **업무** | 노트, 프로젝트 보드 |
| **더 보기** | Arcade 창, 설정, 🌐 언어, 🐞 오류 신고하기, ☕ 프로젝트 후원하기 |

섹션 제목을 누르면 접거나 펼칠 수 있습니다. 접힌 섹션에는 `▸`와 그 안의 타일 수가 표시되고, *소통*에는 새 메시지 💬와 친구 요청 👥 수도 표시됩니다. 어떤 섹션을 접었는지 Arcade가 기억합니다. 필요 없는 섹션은 **설정**에서 숨길 수 있습니다. 숨긴 섹션은 제목과 타일까지 메뉴에서 완전히 사라지며, 설정이 있는 *더 보기*는 항상 남아 있습니다. 로그인하면 메뉴 머리글에 @닉네임과 같은 카운터가 표시됩니다.

**검색**은 두 글자부터 시작하며, 대소문자와 악센트를 구분하지 않고 제목과 장르를 찾습니다. 결과는 *게임 · 슈팅*처럼 섹션과 장르별로 묶입니다. 게임 옆의 ☆을 누르면 **★ 즐겨찾기**에 추가되며(최대 100개), 섹션과 장르별로 최근 항목부터 정렬됩니다. 책과 오디오북에는 제목이나 저자로 찾는 별도의 검색이 있습니다.

### 어디서 열리나요

| | NES(Dendy), Flappy Arcade | Sega, 마스터 시스템, PlayStation, 그 밖의 게임, 책, 오디오북, 아티클, 팟캐스트, 영상 |
|---|---|---|
| **터미널** | 패널 안(터미널이 지원하면 픽셀 그래픽, 아니면 텍스트 블록) | 브라우저 창 |
| **VS Code** | 패널 안 | 브라우저 창 |
| **Claude Desktop** | 패널 안 | Claude 내장 브라우저 또는 브라우저 창(설정에서 선택). 슈팅 게임은 항상 브라우저 창 |

브라우저 창은 기본 브라우저(또는 설정에서 고른 브라우저)로 여는 별도의 Arcade 창으로, 평소 쓰는 탭과 섞이지 않습니다. 채팅은 터미널과 Desktop 모두 패널 안에서 바로 쓸 수 있고, *페이지로 열기*를 누르면 사이트에서 같은 방식으로 열립니다. 노트와 프로젝트 보드는 패널 안에 있습니다. TikTok은 Desktop에서는 Claude 내장 브라우저에서, 그 밖의 환경에서는 이미 로그인되어 있을 가능성이 높은 기본 브라우저에서 열립니다.

각 게임 카드는 해당 라이선스와 소스 코드로 연결됩니다.

**주제.** 아티클, 팟캐스트, YouTube는 주제에서 시작합니다. Haiku가 에이전트의 작업 내용에 맞춰 세 가지를 제안하고, 여기에 *신제품과 발표*가 더해집니다. *나만의 주제*에는 보고, 읽고, 듣고 싶은 것을 어떤 언어로든 입력할 수 있습니다. 최근 주제 다섯 개는 *내 주제* 타일로 남습니다.

## 온라인 플레이

- **콘솔.** NES, Sega, 마스터 시스템, PlayStation의 2인용 게임에는 **온라인** 버튼이 있습니다. 방을 만들거나 다른 사람의 방에 참가하세요. 입력은 Arcade 서버를 통해 프레임 단위로 동기화됩니다.
- **Doom.** **FreeDM**과 **BlasphDM**은 최대 4명, 라운드당 5분의 데스매치 로비입니다. **Freedoom**과 **Blasphemer**는 **온라인**으로 협동 플레이를 할 수 있습니다. 새로 들어온 플레이어는 다음 라운드를 기다립니다 — 엔진 특성상 진행 중인 경기에는 참가할 수 없습니다.
- **보드게임.** *상대 찾기*, 링크로 *친구 초대*, 또는 *컴퓨터와 대전*. 대국은 서버에 저장되므로, 한 수 두고 에이전트로 돌아갔다가 나중에 링크를 열면 판이 그대로 남아 있습니다. @닉네임으로 로그인했다면 상대는 내 돌 색 옆에서 닉네임을 보게 됩니다.
- **기다리는 사람.** Arcade는 1분마다 상대를 기다리는 사람이 있는지 확인해 Claude Code에 보여 줍니다 — 예: *「플레이할까요? 온라인 대기: FreeDM (1)」* — 메뉴에는 **참가** 버튼이 나타납니다.

## 계정, 친구, 채팅

로그인은 선택 사항입니다. 로그인하지 않아도 나머지는 모두 그대로 작동합니다.

- **GitHub로 로그인**(*소통* 안): 평소 쓰는 브라우저에 GitHub 로그인 페이지가 열립니다. 거기서 승인한 뒤 Arcade 페이지에서 *Sign in*을 누르세요 — 페이지의 코드가 패널의 코드와 같아야 합니다. 브라우저로 안 될 때는 *코드로 로그인*: Arcade가 보여 주는 코드를 GitHub 페이지에 입력합니다. Arcade가 알게 되는 것은 GitHub 프로필 이름과 사진뿐입니다 — 이메일도, 저장소 접근 권한도 받지 않습니다.
- **동기화.** 언어, 키, 알림, 패널 크기, 에이전트가 신호를 보낼 때 게임을 어떻게 할지, Desktop 브라우저 설정, 주제, Twitch 채널, 즐겨찾기, 접은 섹션과 숨긴 섹션, Flappy Arcade 최고 기록이 모든 컴퓨터에서 같아집니다. 내 게임, 브라우저, 그래픽 모드는 컴퓨터마다 따로 유지됩니다.
- **@닉네임.** 클릭 한 번으로 GitHub 이름을 쓰거나 직접 만드세요: 4~32자, 라틴 문자·숫자·`_`. 하루에 5번까지 바꿀 수 있습니다.
- **친구.** 정확한 @닉네임으로 친구를 추가합니다. 상대가 요청을 수락하면 서로의 목록에 나타납니다. 입력 중에 추천이 뜨지 않으므로 누가 Arcade를 쓰는지 훑어볼 수 없습니다. 거절이나 삭제는 상대에게 알려지지 않습니다.
- **온라인 상태와 게임 초대.** Arcade 메뉴가 열려 있는 동안 친구에게 내가 *온라인*으로 보이고, 나도 친구를 볼 수 있습니다. 보이고 싶지 않다면 *친구* 화면에서 *친구에게 온라인 상태 표시*를 끄세요. 친구 옆의 *초대*를 누르면 네트워크 게임을 고를 수 있습니다. 보드게임은 둘만의 방을, Doom 게임은 그 게임의 로비를 엽니다. 게임은 내 쪽에서 바로 열리고, 친구에게는 알림과 메뉴 위쪽의 *수락* 버튼이 나타나며, 초대는 10분 동안 유효합니다. 초대는 네트워크 게임이 브라우저에서 열리는 곳에서 할 수 있습니다. Desktop의 내장 브라우저나 브라우저 창입니다.
- **채팅.** 친구와 1:1, 친구 그룹, 또는 한 번에 모든 친구가 들어간 그룹. Arcade 패널에서 바로 쓰거나 사이트의 채팅 페이지를 여세요. 메시지는 Arcade 사이트에 저장되며 암호화되지 않습니다 — 비밀번호나 키는 쓰지 마세요.
- **아바타와 메시지 알림.** *계정*에서 미리 만들어진 아바타 24개 중 하나를 고르세요. 채팅은 그것을 보여 주기만 하며, 아바타가 없으면 @닉네임의 첫 글자가 표시됩니다. 그룹 이미지는 그룹 소유자가 같은 24개 중에서 고릅니다. GitHub 프로필 사진은 다른 사람에게 절대 보이지 않습니다. 친구가 메시지를 보내면 왼쪽 아래에 모든 창 위로 카드가 뜨거나(Windows) 시스템 알림이 옵니다(macOS, Linux). 카드를 클릭하면 그 채팅이 열립니다.
- **로그아웃**하면 이 컴퓨터에서 동기화가 멈춥니다. **계정 삭제**(두 번 누르기)를 하면 사이트에서 계정과 설정이 지워집니다.

## 노트와 프로젝트 보드

둘 다 메뉴의 *업무* 섹션에 있습니다.

- **노트.** 페이지와 하위 페이지. `# `로 시작하는 줄은 제목, `- `는 항목, `- [ ] `는 누르면 체크되는 체크리스트 항목입니다. 이 컴퓨터에 저장되며, 최대 200페이지, 페이지당 20,000자까지입니다.
- **Claude도 함께 씁니다.** *Claude에게 넘기기*로 페이지를 Claude에게 넘기거나, 그냥 Claude에게 Arcade에 뭔가 적어 달라고 부탁하세요. Claude는 `mcp__arcade__notes` 도구를 쓰며, 이 도구는 노트만 바꾸고 아무것도 삭제하지 않습니다. Claude가 고친 내용이 마음에 들지 않으면 *Claude가 고치기 전 글로 되돌리기*를 누르세요.
- **Notion과 다른 앱** — Claude의 커넥터를 통하므로 Arcade에는 키나 비밀번호가 필요 없습니다: *Notion으로 보내기*, *다른 앱으로*, *Notion이나 다른 앱에서 가져오기*. 연결된 페이지는 그 앱에서 업데이트하거나 그 앱에서 다시 가져올 수 있습니다.
- **음성.** 시스템 자체 받아쓰기(Windows에서는 Win+H, macOS에서는 Fn 두 번)로 Claude 입력창에 받아쓴 뒤 *Claude 입력창에서 가져오기*를 누르면 텍스트가 페이지 끝으로 옮겨집니다.
- **프로젝트 보드.** 열(*할 일*, *진행 중*, *완료* 또는 직접 만든 열, 최대 8개)과 카드. 카드는 텍스트와 체크리스트가 있는 노트 페이지입니다. 카드를 누르면 선택되어 방향키로 옮길 수 있고, 한 번 더 누르면 열립니다. Claude도 보드를 다룰 수 있습니다: *Claude에게 넘기기*를 누르거나, Arcade 보드에 작업을 정리해 달라고 부탁하세요.
- **공유 보드.** @닉네임으로 로그인한 상태에서 친구를 체크하고 *공유*를 누르세요. 카드, 열, 이름이 모두에게 같고, 변경 사항은 몇 초 안에 반영됩니다. 소유자는 친구를 더 초대하고, 참여자를 내보내고, 사이트에서 보드를 삭제할 수 있습니다. 누구나 나갈 수 있으며, 무슨 일이 있어도 각자 자기 사본은 남습니다. 내 공유 보드는 최대 3개, 보드 하나에 20명, 카드 200장까지입니다.

## 내 게임

- **`/arcade-add <파일>`** 로 NES, 메가 드라이브, 마스터 시스템 ROM(최대 4 MB)을 추가합니다. 플러그인은 `~/.claude/arcade`에 사본을 보관하며 어디에도 업로드하지 않습니다.
- **PlayStation 디스크와 Doom WAD**(예: 직접 소유한 `doom.wad`)는 Arcade 창의 **내 파일 열기**에서. 그 브라우저 안에만 저장됩니다.

권리가 있는 파일만 추가하세요.

## 설정

`/arcade` 메뉴의 *더 보기* 섹션에서 **설정**을 엽니다:

- **메인 메뉴 섹션** — *더 보기*를 뺀 모든 섹션을 표시하거나 숨깁니다. 숨긴 섹션은 여기서 다시 표시할 때까지 메뉴에서 완전히 사라집니다. Arcade를 처음 열 때도 같은 선택을 할 수 있습니다.
- **언어** — 13개 중 선택(메뉴의 🌐에서도 바로 바꿀 수 있습니다).
- **게임 여는 곳** — 여기(패널), 브라우저 창, 또는 특정 브라우저. Claude Desktop에서는 Claude 내장 브라우저나 브라우저 창.
- **그래픽**(터미널) — 이미지를 표시하는 터미널(kitty, Ghostty, Rio)에서는 픽셀, 그 외에는 텍스트 블록.
- **패널 크기** — 보통 또는 전체 너비.
- **에이전트 작업 완료 시** — 배너를 띄우고 계속 플레이, 배너와 함께 일시 정지, 또는 곧바로 에이전트로 돌아가기.
- **에이전트 권한 요청 시** — 같은 세 가지 선택지.
- **브라우저가 열릴 때**(Claude Desktop) — 브라우저가 높이를 꽉 채우도록 Arcade 메뉴 닫기, 또는 메뉴를 브라우저 위에 유지.
- **보는 중 에이전트 완료 시**(Claude Desktop) — Arcade가 영상, 방송, TikTok, 아티클, 에피소드를 위해 연 탭을 닫아 Claude와의 대화를 다시 눈앞에 띄우기, 또는 알림만.
- **창에서 플레이 중 알림.**
- **메시지 알림** — 친구가 채팅에 글을 쓰면 왼쪽 아래에 카드가 뜹니다(macOS와 Linux에서는 시스템 알림).
- **키 테스트와 키 재설정**(터미널).
- **약관 및 개인정보** — 사이트의 이용 약관과 개인정보 처리방침을 평소 쓰는 브라우저에서 엽니다.

## 플러그인이 내 컴퓨터에서 하는 일

Arcade는 Claude Code가 플러그인에 주는 권한 안에서 Claude Code 내부에서 실행됩니다. 코드는 모두 이 저장소에 있으며, `claude plugin validate ./mod`를 실행하면 연결된 모든 이벤트와 모든 호출이 나열됩니다. 요약하면 다음과 같습니다:

- **에이전트의 도구.** Arcade는 도구가 언제 시작하고 끝나는지, 에이전트가 언제 권한을 요청하는지 봅니다. 그래야 배너를 언제 띄울지 알 수 있습니다. 에이전트의 도구 호출을 바꾸거나 막는 일은 절대 없습니다. Arcade가 직접 허용하는 호출은 두 가지뿐이며, 그것도 Claude Code가 원래 사용자에게 물어볼 경우에만 해당합니다: 노트만 바꾸고 아무것도 삭제하지 않는 `mcp__arcade__notes`, 그리고 패널에서 누른 게임을 Desktop 내장 브라우저에서 여는 것입니다. 허용·거부 규칙은 그대로 적용됩니다.
- **에이전트 중단.** Claude Desktop에서만, 에이전트가 작업하는 동안 내장 브라우저에서 무언가를 열 때 일어납니다. Desktop은 플러그인이 직접 브라우저를 열도록 허용하지 않기 때문입니다. Arcade는 실행 중인 도구가 끝나기를 기다렸다가(10초가 지나면 중단하지만, 권한 확인 창이 떠 있는 동안에는 기다립니다) 에이전트를 멈추고, Claude에게 페이지를 연 뒤 작업으로 돌아가 달라고 요청합니다. 이를 피하려면 *설정 → 게임 여는 곳*에서 브라우저 창을 고르세요.
- **대화.** 주제 추천을 위해 내 세션의 Haiku가 대화의 마지막 몇천 자를 받습니다. 이는 Claude 사용량에 포함됩니다. Arcade 사이트는 대화를 볼 수 없습니다. Arcade가 입력창에 쓰거나 전송하는 것은 사용자가 요청할 때(예: 노트의 *Claude에게 넘기기*)나 위에서 설명한 대로 페이지를 열 때뿐입니다.
- **실행하는 프로그램.** Arcade 창을 위한 브라우저(Windows에서는 `%LOCALAPPDATA%\claude-arcade`의 별도 프로필 사용), 알림(Windows는 PowerShell, macOS는 `osascript`, Linux는 `notify-send`), 설치된 브라우저 확인(Windows) 또는 OS 확인(`uname`).
- **파일.** `/arcade-add`로 추가한 ROM만 `~/.claude/arcade/roms`에 씁니다. 읽는 것은 지정한 파일, 그 사본, 그리고 플러그인 자체 파일뿐입니다. 설정, 노트, 즐겨찾기는 Claude Code의 플러그인 저장소에 보관됩니다.
- **환경 변수.** `HOME` 또는 `USERPROFILE`, `LANG`, `LC_ALL`, `LC_MESSAGES`, `LOCALAPPDATA`, `OS`를 읽으며 어느 것도 바꾸지 않습니다.
- **네트워크.** 플러그인 자체는 Arcade 사이트(`agent-arcade.fefaodessa.workers.dev`), YouTube 채널의 RSS 피드, 그리고 보여 주는 블로그와 팟캐스트의 피드와만 통신합니다. Desktop 패널의 이미지(예: Twitch 아바타)는 해당 서비스에서 바로 불러옵니다. 게임, 책, 동영상은 브라우저에서 연 페이지가 불러옵니다.

- 내 ROM, WAD, 책, 오디오 파일은 내 컴퓨터나 브라우저 밖으로 나가지 않습니다.
- 책과 오디오북 목록, 그리고 Project Gutenberg 책은 Arcade 사이트를 거칩니다. 사이트는 이를 Project Gutenberg, Wikisource, archive.org에서 가져와 Cloudflare 캐시에만 둡니다(목록은 6시간, 책은 1주일). Wikisource 페이지와 LibriVox 녹음은 창이 해당 사이트에서 바로 불러옵니다.
- 온라인 플레이는 Cloudflare에 있는 Arcade 서버를 거칩니다. 메시지는 방 안의 플레이어 사이에서 전달될 뿐 저장되지 않습니다 — 다만 나중에 돌아올 수 있도록 보드게임의 수는 저장되며, 한 달 동안 아무도 두지 않은 대국은 삭제됩니다.
- 주제는 내 Claude Code 세션 안에서 Haiku가 제안합니다. Arcade 사이트는 대화를 볼 수 없으며, *나만의 주제*를 쓸 때 짧은 영어 검색어만 받습니다. 아티클 주소는 `#` 뒤에 붙기 때문에 Arcade 서버에 전달되지 않습니다.
- *나만의 주제* 검색은 YouTube API Services를 거치고, 동영상은 YouTube 자체 플레이어에서 재생되므로 [YouTube 서비스 약관](https://www.youtube.com/t/terms)과 [Google 개인정보처리방침](https://policies.google.com/privacy)도 적용됩니다. 보여 줄 동영상 최대 6개는 내 세션의 Haiku가 제목과 짧은 설명을 보고 고릅니다. Arcade 사이트는 검색 결과를 공유 캐시에 하루 동안 보관합니다.
- 로그인하면 사이트는 동기화된 설정, 즐겨찾기, @닉네임, 친구, 채팅, 공유 보드를 보관하고, 게임 초대는 10분 동안 보관합니다. 누가 온라인인지는 메모리에만 1분 30초 동안 둡니다. 세션 키는 Arcade 사이트로만 전송됩니다.
- 노트는 내 컴퓨터에 남습니다. 공유 보드는 채팅과 마찬가지로 Arcade 사이트에 저장되며 암호화되지 않습니다. 페이지는 내가 요청할 때만, 내 Claude 커넥터를 통해 Notion이나 다른 앱으로 전송됩니다.
- 오류 신고에는 내가 쓴 내용, Arcade 버전, 열려 있는 환경, 인터페이스 언어, OS만 담깁니다. 로그인하지 않았다면 서명 없이 전송되며, 사이트는 주소를 저장하지 않습니다.
- 일부 게임은 내가 요청할 때만 인터넷에 접속합니다 — 예를 들어 OpenTTD의 선택형 설문과 *Online Content* 버튼.

## 플랫폼과 상태

## 프로젝트 후원하기

Arcade는 무료입니다. 기다리는 시간이 더 즐거워졌다면 프로젝트에 커피 한 잔을 사 주셔도 좋습니다 — 전적으로 자율입니다: **[ko-fi.com/agentarcade](https://ko-fi.com/agentarcade)**. 같은 링크가 `/arcade` 메뉴 하단(*☕ 프로젝트 후원하기*)과 Arcade 창에도 있습니다. Arcade의 어떤 기능도 후원 여부에 좌우되지 않으며, 게임을 방해하지도 않습니다.

## 피드백

오류를 발견했나요? 가장 빠른 방법은 Arcade에서 바로 보내는 것입니다: **더 보기 → 🐞 오류 신고하기**. 무엇이 잘못됐는지 적으면 버전, 환경, 언어, OS와 함께 Arcade 제작자에게 바로 전달됩니다.

[이슈](https://github.com/ArbakovMaxim/agent-arcade/issues)를 열어도 됩니다 — 오류든 아이디어든 좋습니다. OS, Claude Code 환경(터미널, VS Code, Desktop 중 무엇인지), 게임 이름을 적어 주세요.

풀 리퀘스트도 환영합니다. 풀 리퀘스트를 보내면 기여한 내용이 AGPL-3.0으로 라이선스되고, 제작자가 Arcade를 다른 조건(예: 상업용 라이선스)으로도 제공할 수 있다는 데 동의하는 것으로 간주합니다.

## 개발자용

```
mod/     Claude Code 플러그인(훅, 패널 UI, 테스트)
site/    Cloudflare Workers 기반 사이트: 카탈로그, Arcade 창, 네트워크 방, 계정, 친구, 채팅, 오류 신고
tools/   빌드 도구: 번역, heretic-wasm
.github/ 브라우저용 doom-wasm, heretic-wasm, OpenTTD, ScummVM을 빌드하는 GitHub Actions
```

- 저장소에서 플러그인 실행: `claude --plugin-dir ./mod`
- 플러그인 테스트: `claude plugin validate ./mod`, 그다음 `mod/`에서 `claude plugin test`
- 사이트 테스트: `site/`에서 `npm test`. 빌드: `node build.mjs`. 배포는 Cloudflare Workers Builds를 통해 `main`에서 자동으로 이루어집니다.
- 작업은 `main`에서 하고 풀 리퀘스트도 `main`으로 보내 주세요. 기본 브랜치 `plugin`은 `site/`를 뺀 `main`의 복사본으로, 푸시할 때마다 GitHub Action이 갱신합니다. 플러그인 마켓플레이스는 저장소 전체 대신 이 브랜치를 내려받습니다.
- 번역: `node tools/i18n/collect.mjs`, 그다음 `node tools/i18n/check.mjs` — [tools/i18n/README.md](tools/i18n/README.md) 참고.

자세한 문서(러시아어): [mod/README.md](mod/README.md) — 플러그인, [site/README.md](site/README.md) — 사이트, 게임 추가, 네트워크 플레이.
