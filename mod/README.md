# Arcade — пробная игровая платформа для Claude Code

Пока агент работает, мод предлагает поиграть. На Windows игра открывается отдельным окном браузера рядом с терминалом — с настоящими пикселями, звуком и геймпадом, в каком бы терминале ты ни работал. На других ОС и по выбору — прямо в панели Claude Code.

## Что внутри

- `.claude-plugin/plugin.json` — манифест.
- `hooks/hooks.json` — указывает Claude Code на код мода.
- `hooks/register.js` — платформа: события агента, вопрос «сыграть?», панель, библиотека, управление.
- `hooks/input.js` — экран игры ловит клавиши: что зажато и сколько раз нажато.
- `hooks/nes-screen.js` — Денди в панели: эмулятор, кадр в PNG для картинки и в символы для остальных терминалов.
- `hooks/browsers.js` — окно игры на Windows: поиск браузеров, размер и место окна, команда запуска.
- `web/` — окно браузера: библиотека с приставками и статистикой (`library.js`, `stats.js`), игра (`game.js`), каталог с ROM (`games.js`), эмулятор (`jsnes.js`).
- `hooks/roms/` — ROM игр для Денди в панели.
- `hooks/vendor/jsnes.mjs` — эмулятор JSNES 2.1.0.
- `hooks/roms/thwaite.mjs` — игра Thwaite для Денди.
- `third_party/` — лицензии JSNES и Thwaite и исходники Thwaite.
- `tests/arcade.test.ts` — тесты, которые запускает сам Claude Code.
- `tests/web-page.mjs` — проверка страницы игры без браузера, на поддельном DOM.

## Запуск

Нужен Claude Code 2.1.287 или новее.

```bash
claude plugin validate ./arcade
claude --plugin-dir ./arcade
```

Панель открывается командой `/arcade` или ответом `1` на вопрос «сыграть?», который появляется, когда агент работает дольше 20 секунд.

В панели — меню:

- **Денди** — список игр; «← Назад» возвращает в меню;
- **Sega** — скоро;
- **Окно Arcade** (на Windows) — все игры и статистика в окне браузера;
- **Настройки** — где открывать игры, графика в панели, проверка клавиш.

Стрелки вверх и вниз или Tab выбирают пункт, Enter открывает, можно кликнуть мышью. Из игры в панели Backspace возвращает в список её приставки.

## Окно с игрой (Windows)

Кнопка «Окно Arcade» в меню Claude Code открывает окно с библиотекой: вкладки приставок (Денди, Sega), карточки игр со статистикой. Стрелки вверх и вниз выбирают игру, влево и вправо — приставку, Enter запускает. Из игры обратно — ссылка «← Библиотека» внизу окна. Игру можно открыть и сразу, кнопкой с её названием.

Кнопка «Открывать» в «Настройках» переключает, где запускать игры:

- **окно браузера по умолчанию** — так стоит с самого начала;
- **окно конкретного браузера** — мод сам находит установленные Chrome, Edge, Brave, Vivaldi, Opera и Firefox;
- **здесь, в панели** — как раньше.

Chrome, Edge, Brave, Vivaldi и Opera открывают игру отдельным окном без вкладок и адресной строки, справа на главном экране. Кадр в нём увеличен в целое число раз, от двух до четырёх, сколько влезает. У такого окна свой профиль браузера в `%LOCALAPPDATA%\claude-arcade\<браузер>`: он не смешивается с твоими вкладками и хранит сохранения игр. Папку можно удалить в любой момент, вместе с ней пропадут сохранения. Firefox открывает игру обычным новым окном.

В окне:

- прицел и движение — стрелки или WASD, огонь — Z и X или J и K, Start — Enter, Select — Shift; клавиши берутся по месту на клавиатуре, раскладка не важна;
- геймпад работает сам, со стандартной раскладкой;
- звук включается кнопкой внизу окна;
- игра стоит на паузе, пока окно не в фокусе, и сохраняет прогресс; следующее окно продолжит с того же места, а кнопка «Сначала» начнёт заново.

### Статистика

Окно считает по каждой игре:

- сколько раз в неё играли: партия засчитывается, когда игра впервые пошла, а «Сначала» начинает новую;
- сколько времени: только пока игра не на паузе;
- когда играли последний раз;
- рекорд — у игр, которые хранят счёт в известном месте памяти: в Thwaite это очки, в robotfindskitten — найденные котята. Рекорд виден внизу окна во время игры.

Статистика видна в карточках библиотеки, а сверху — общее время. Хранится она в профиле браузера Arcade (`%LOCALAPPDATA%\claude-arcade\<браузер>`), поэтому у каждого браузера своя. В режиме «в панели» статистика пока не ведётся.

Мод ищет браузеры при старте сессии в фоне, PowerShell на это тратит около полсекунды.

## Графика в панели

Когда игры открываются в панели, в «Настройках» есть переключатель «Графика»:

- **авто** (по умолчанию) — пиксели, если терминал умеет картинки, иначе через полсекунды сам переходит на символы и говорит об этом;
- **пиксели** — настоящий кадр Денди 256×240 картинкой, чётко, как в эмуляторе;
- **символы** — кадр из квадрантов ▘▝▖▗: на символ четыре «пикселя» и два цвета. Работает в любом терминале, но мелкий текст игр сливается.

Картинки показывают kitty и Ghostty на macOS и Linux. На Windows их показывает Rio, его нужно один раз настроить (так же, как для intermission):

1. Поставь Rio: `winget install -e --id raphamorim.rio`.
2. Дай Rio ConPTY 1.22 или новее. В PowerShell от администратора скопируй `conpty.dll` и `OpenConsole.exe` из пакета Microsoft рядом с `rio.exe`:
   ```powershell
   curl.exe -L -o "$env:TEMP\conpty.zip" https://www.nuget.org/api/v2/package/Microsoft.Windows.Console.ConPTY
   Expand-Archive "$env:TEMP\conpty.zip" "$env:TEMP\conpty" -Force
   Copy-Item "$env:TEMP\conpty\runtimes\win-x64\native\conpty.dll", "$env:TEMP\conpty\build\native\runtimes\x64\OpenConsole.exe" "C:\Program Files\Rio"
   ```
3. Скажи Claude Code, что в Rio можно рисовать картинки: в начало файла `%USERPROFILE%\AppData\Local\rio\config.toml` добавь строку `env-vars = ["CLAUDE_CODE_FORCE_TERMINAL_IMAGES=1"]`. Только в Rio: в других терминалах эта настройка выведет мусор вместо картинок.
4. Открой новое окно Rio и запусти Claude Code с модом.

В режиме символов размер экрана упирается в высоту терминала. Разверни окно на весь экран и уменьши шрифт (в Windows Terminal — Ctrl и минус): чем больше строк, тем чётче экран.

## Игры

Денди:

- **Thwaite** — ракеты падают на город, сбивай их фейерверками. На заставке нажми Start, выбери «1 Player» и снова Start.
- **Concentration Room** — переворачивай карточки и находи пары: одному, вдвоём или против компьютера.
- **robotfindskitten** — робот ищет котёнка среди странных предметов, без врагов и таймера.

Sega (Mega Drive) пока на вкладке «скоро».
- **Проверка клавиш** (в «Настройках») — поле: видно, что нажато и что мод считает зажатым.

Из игры в список её приставки — Backspace.

## Управление

| Кнопка Денди | Клавиши по умолчанию |
| --- | --- |
| вверх, влево, вниз, вправо | W A S D или стрелки (Ц Ф Ы В, украинская І вместо Ы, Z Q S D на AZERTY) |
| A — огонь из правой шахты | K (Л) |
| B — огонь из левой шахты | J (О) |
| Start — начать, пауза | N (Т) |
| Select | M (Ь) |

- Чтобы играть, кликни по экрану игры — пока клика не было, поверх экрана написано «Кликни сюда, чтобы играть». После клика клавиши идут в игру, в любой раскладке. Esc возвращает клавиатуру полю ввода Claude Code, и для игры снова нужен клик.
- Если нажать клавишу, которой мод не знает, панель предложит назначить управление: по очереди нажать клавиши для всех восьми кнопок. Назначение сохраняется для всех сессий. `/arcade-keys` — назначить заново.
- Терминал не сообщает, когда клавишу отпустили. Поэтому клавиша считается зажатой 260 мс после первого нажатия и 120 мс после каждого повтора, пока идёт автоповтор. Повторное нажатие уже зажатой кнопки игра видит как новое: второй выстрел подряд срабатывает. Если удержание дёргается, уменьши в системе задержку перед повтором клавиш (на Windows: Панель управления → Клавиатура) или поправь числа в начале `hooks/input.js`. На поле «Проверка клавиш» видно, какие клавиши мод сейчас считает зажатыми.
- Enter, Esc и цифры в играх не используются: ими отвечают на запросы Claude Code.

## Тесты

Из папки мода:

```bash
claude plugin test
node tests/web-page.mjs
```

Первая команда загружает мод в движок Claude Code без сессии и сети, рисует панель для терминала и Desktop, гоняет Денди на виртуальных часах и проверяет запуск окна на Windows с подставным поиском браузеров. Вторая проверяет страницу игры на поддельном DOM.

## Настройки в коде

В начале `hooks/input.js` — сколько держать клавишу после нажатия и между повторами. В начале `hooks/register.js`:

- `ASK_AFTER_MS` — порог вопроса, по умолчанию 20 секунд.
- `PANE_COLUMNS`, `PANE_ROWS` — какой размер панели просить у Claude Code.
- `DEBUG` — тост в начале каждого хода.

## Известные ограничения

- Окно браузера пока открывается только на Windows. На macOS и Linux игры идут в панели.
- Окно не открывается, если Claude Code запущен по SSH (браузер открылся бы на сервере) и в Desktop-приложении (там мод не запускает программы). В организациях администратор может запретить модам запускать программы.
- Когда агент закончил, окно с игрой само не уходит назад: мод пишет об этом в Claude Code. Возврат фокуса в терминал — следующий шаг.
- Денди и поле рисуются в панели только в терминале, в Desktop-приложении вместо них текст.
- Звука нет.
- В режиме пикселей мод отправляет терминалу около 2 МБ в секунду: кадр — PNG с палитрой, около 60 КБ, 30 раз в секунду. Одинаковые кадры не отправляются.
- Пока вопрос виден, мод занимает полосу над полем ввода целиком и скрывает то, что рисуют там другие моды.
