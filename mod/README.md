# Arcade for Claude Code

This folder is the plugin itself: task boards Claude picks up, a notebook it keeps with you, a calendar, team chats, and games while the agent works.

The README for users is at the root of the repository: [README.md](../README.md). It covers installation, every feature, what the plugin does on your computer, the network, privacy and licenses. The default branch `plugin` carries a copy of it in this folder, which is what the Claude plugin directory shows.

Developer documentation (in Russian): [docs/README.ru.md](docs/README.ru.md).
