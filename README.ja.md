# Arcade — Claude Code のエージェントが作業している間に、遊んで、読んで、聴いて、観る

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · **日本語** · [中文](README.zh.md) · [한국어](README.ko.md)

> **ベータ版（0.33）。** ここに書かれていることはすべて動作し、毎日使われています。これからの変更は主に細かな部分です。不具合の報告は大歓迎です — [フィードバック](#フィードバック)をご覧ください。

Arcade は、エージェントが作業している間の待ち時間を埋める [Claude Code](https://claude.com/claude-code) 用プラグインです。エージェントの作業が 10 秒を超えると、プロンプトの上に小さく *「プレイしますか？」* と表示されます。NES、Sega、PlayStation、Doom、チェスなどで遊んだり、本を読んだり、オーディオブックやポッドキャストを聴いたり、エージェントが取り組んでいるテーマの動画を観たりできます。エージェントが作業を終えたり許可を求めたりすると、Arcade がすぐに知らせるので、何も見逃しません。

カタログはすべて無料です。ゲームはオープンライセンス、本とオーディオブックはパブリックドメインです。同じようにエージェントを待っているほかの人とオンラインで遊んだり、フレンドとチャットしたりもできます。

![エージェントが 11 秒作業したあと、Claude Code のプロンプトの上に表示された「プレイしますか？」](docs/images/prompt.png)

## 機能

- **自動で現れる。** エージェントが 10 秒作業すると、Arcade がプロンプトの上でゲームを提案します。こちらから求めない限り、フォーカスを奪うことはありません。
- **エージェントの状況がわかる。** エージェントが作業を終えたり許可を求めたりすると、ゲームの上にバナーが表示されます。プレイを続ける、一時停止する、すぐエージェントに戻る — 動作は設定で選べます。Claude Desktop では、観ているタブを閉じて、会話を再び目の前に戻すこともできます。
- **1 つのメニュー、6 つのセクション。** *プレイ*、*読む・聴く*、*視聴*、*コミュニティ*、*仕事*、*その他* — 不要なものは折りたためます。いちばん上には、前回のゲームを *続ける*、*検索*、*お気に入り* があります。Arcade を初めて開いたときに、表示するセクションを選べます。
- **61 本の無料ゲーム。** NES（Dendy）、Sega メガドライブ、マスターシステム、PlayStation に加え、アーケード、シューティング、レース、ストラテジー、アドベンチャー、ボードゲームをそろえた *ゲーム* タブ。
- **読む・聴く。** 30 言語の名作と LibriVox のオーディオブックを Project Gutenberg、Wikisource、LibriVox から直接。エージェントの作業テーマに沿った最新の記事とポッドキャストのエピソードも。
- **視聴。** エージェントの作業テーマに沿った最新の YouTube 動画と Twitch：自分のチャンネルのほか、プログラミング、テクノロジー、サイエンス、レトロゲームのライブ配信。さらに TikTok：TikTok 公式サイトで見る *「おすすめ」フィード* と検索（サインインは自分で行います）。
- **NES と Flappy Arcade は Claude Code の中でそのまま動く** — ターミナル、VS Code、Claude Desktop のいずれでも。それ以外はブラウザーウィンドウで開きます。Claude Desktop では、既定で Claude の内蔵ブラウザーで開きます（シューティングは内蔵ブラウザーがマウスをキャプチャできないため、ブラウザーウィンドウで開きます）。
- **オンラインプレイ。** ネットワーク越しの 2 人用コンソールゲーム、Doom のデスマッチと協力プレイ、人やコンピューターを相手にしたチェス、囲碁、チェッカー、リバーシ。
- **「オンラインで待っている人」。** 誰かが対戦相手を待っていると、Arcade が Claude Code に *参加* ボタン付きで表示します。
- **フレンドとチャット。** 任意の GitHub サインインで、どのコンピューターでも設定がそろい、@ニックネームを持てます。正確なニックネームでフレンドを追加し、誰がオンラインかを確認し、ゲームに招待し、1 対 1 やグループでチャットできます。
- **ノートとプロジェクトボード。** Claude も書き込めるページ、サブページ、チェックリスト。Claude のコネクタ経由で、ページを Notion や別のアプリに送ったり、そこから取り込んだりできます。Claude の入力欄に音声入力して、その文字をページに移すことも。列とカードのあるボードはフレンドと共有でき、全員が同じボードで作業します。
- **検索とお気に入り。** ゲームと Twitch チャンネルを一度に検索でき、結果はセクションとジャンルごとにまとまります。☆ を付けたゲームは *★ お気に入り* に入ります。
- **自分のゲーム。** 持っている ROM を追加できます。ROM は自分のマシンから出ません。
- **13 のインターフェース言語：** English、Русский、Українська、Español、Français、Deutsch、Português、Italiano、Polski、Türkçe、日本語、中文、한국어 — システムまたはブラウザーの言語に合わせ、既定は英語です。

## インストール

**Claude Code 2.1.275 以降** が必要です。

ターミナルで 2 つのコマンドを実行します。Arcade のマーケットプレイス（このリポジトリ）を追加し、そこからプラグインをインストールします：

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

または Claude Code のセッション内で：

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

プラグインはすべてのセッションとアプリにインストールされます。VS Code 拡張機能には `/plugin` コマンドがないので、ターミナルからインストールしてください。新しい会話で拡張機能に読み込まれます。

**アップデート：**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

その後 Claude Code を再起動します。マーケットプレイスがダウンロードするのはプラグインだけ（数 MiB、サイトは含みません）なので、アップデートは数秒で終わります。すでに Arcade をインストールしている場合は何もする必要はありません。次のアップデートでマーケットプレイスが自動的に切り替わります。

`/plugin update` が *already at the latest version* と表示するのに新しいバージョンの Arcade が出ている場合は、マーケットプレイスが更新されていません。ターミナルで `claude plugin marketplace update agent-arcade` を実行すると理由がわかります。*timed out* と表示されたら、クローンに 10 分の猶予を与えます：

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

PowerShell では `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade` です。その後、もう一度 `/plugin update arcade@agent-arcade` を実行します。

**アンインストール：** `/plugin uninstall arcade@agent-arcade`

## 使い方

- **`/arcade`** でいつでもメニューを開けます。
- エージェントの作業が 10 秒を超えると、プロンプトの上に *「プレイしますか？」* が表示されます：**`1`** — ここ（パネル）で遊ぶ、**`2`** — ブラウザーウィンドウで（使える場合）、**`3`** — 今はしない。
- 矢印キーか Tab で選び、Enter で開きます。マウスも使えます。操作方法は各ゲームの下に表示されます。
- エージェントが作業を終えたり許可を待ったりすると、ゲームの上にバナーが表示されます：**エージェントに戻る** または **プレイを続ける**。

### メニュー

| セクション | 内容 |
|---|---|
| *（いちばん上）* | 前回のゲームを **▶ 続ける**、**🔍 検索**、**★ お気に入り** |
| **プレイ** | NES、Sega、マスターシステム、PlayStation、ゲーム。オンラインで誰かが待っているときは *参加*。**マイゲーム** |
| **読む・聴く** | 本、オーディオブック、記事、ポッドキャスト |
| **視聴** | YouTube、Twitch、TikTok |
| **コミュニティ** | フレンド、チャット、**GitHub でサインイン**（サインイン後は **アカウント**） |
| **仕事** | ノート、プロジェクトボード |
| **その他** | Arcade ウィンドウ、設定、🌐 言語、🐞 不具合を報告、☕ プロジェクトを支援 |

セクションの見出しをクリックすると折りたたみ・展開できます。折りたたんだセクションには `▸` と中のタイル数が表示され、*コミュニティ* には新着メッセージ 💬 とフレンド申請 👥 の数も表示されます。どのセクションを折りたたんだかは Arcade が覚えています。使わないセクションは **設定** で非表示にできます。見出しもタイルもメニューから完全に消えます。設定がある *その他* は常に表示されます。サインインすると、メニューのヘッダーに @ニックネームと同じカウンターが表示されます。

**検索** は 2 文字から始まり、大文字・小文字やアクセントを区別せずにタイトルやジャンルを探します。結果は *ゲーム · シューティング* のように、セクションとジャンルごとにまとまります。ゲームの横の ☆ を押すと **★ お気に入り** に追加され（最大 100 件）、セクションとジャンルごとに新しい順で並びます。本とオーディオブックには、タイトルか著者で探せる専用の検索があります。

### どこで開くか

| | NES（Dendy）、Flappy Arcade | Sega、マスターシステム、PlayStation、その他のゲーム、本、オーディオブック、記事、ポッドキャスト、動画 |
|---|---|---|
| **ターミナル** | パネル内（ターミナルが対応していればピクセル表示、そうでなければテキストブロック） | ブラウザーウィンドウ |
| **VS Code** | パネル内 | ブラウザーウィンドウ |
| **Claude Desktop** | パネル内 | Claude の内蔵ブラウザーまたはブラウザーウィンドウ（設定で選択）。シューティングは常にブラウザーウィンドウ |

ブラウザーウィンドウは、既定のブラウザー（または設定で選んだブラウザー）で開く独立した Arcade のウィンドウで、普段のタブに混ざることはありません。チャットはターミナルでも Desktop でもパネル内でそのまま使えます。*ページで開く* を選ぶと、同じものがサイトで開きます。ノートとプロジェクトボードはパネル内にあります。TikTok は、Desktop では Claude の内蔵ブラウザーで、それ以外ではおそらくすでにサインイン済みの既定のブラウザーで開きます。

## オンラインプレイ

- **コンソール。** NES、Sega、マスターシステム、PlayStation の 2 人用ゲームには **オンライン** ボタンがあります。ルームを作るか、ほかの人のルームに参加します。入力は Arcade のサーバーを通じてフレーム単位で同期されます。
- **Doom。** **FreeDM** と **BlasphDM** は最大 4 人、1 ラウンド 5 分のデスマッチロビーです。**Freedoom** と **Blasphemer** は **オンライン** から協力プレイができます。新しく来たプレイヤーは次のラウンドを待ちます — エンジンの仕様上、進行中の試合には途中参加できません。
- **ボードゲーム。** *対戦相手を探す*、リンクで *友達を招待*、または *CPU と対戦*。対局はサーバーに保存されるので、一手指してエージェントに戻り、あとでリンクを開けば盤面はそのままです。@ニックネームでサインインしていれば、相手には自分の色の横にそれが表示されます。
- **待っている人。** Arcade は 1 分ごとに対戦相手を待っている人がいるか確認し、Claude Code に表示します — たとえば *「プレイしますか？ オンライン待機中：FreeDM (1)」* — メニューには **参加** ボタンが出ます。

## アカウント、フレンド、チャット

サインインは任意です。サインインしなくても、ほかの機能はこれまでどおり使えます。

- **GitHub でサインイン**（*コミュニティ* 内）：普段使っているブラウザーで GitHub のサインインページが開きます。そこで承認してから、Arcade のページで *Sign in* をクリックします — ページのコードはパネルのコードと同じはずです。ブラウザーでうまくいかないときは *コードでサインイン*：Arcade が表示するコードを GitHub のページに入力します。Arcade が知るのは GitHub プロフィールの名前と画像だけで、メールアドレスやリポジトリへのアクセスは得ません。
- **同期。** 言語、キー設定、通知、パネルサイズ、エージェントからの合図でゲームをどうするか、Desktop のブラウザーの設定、トピック、Twitch チャンネル、お気に入り、折りたたんだセクションと非表示にしたセクション、Flappy Arcade の自己ベストが、すべてのコンピューターで同じになります。自分のゲーム、ブラウザー、グラフィックモードはコンピューターごとのままです。
- **@ニックネーム。** ワンクリックで GitHub の名前を使うか、自分で考えます：4〜32 文字のラテン文字、数字、`_`。1 日に 5 回まで変更できます。
- **フレンド。** 正確な @ニックネームでフレンドを追加します。相手が申請を承認すると、お互いのリストに表示されます。入力中に候補は表示されないので、誰が Arcade を使っているかを一覧で探ることはできません。拒否や削除は相手に通知されません。
- **オンラインとゲームへの招待。** Arcade のメニューを開いている間、フレンドにはあなたが *オンライン* と表示され、あなたにもフレンドが表示されます。表示したくないときは、*フレンド* 画面で *オンラインであることをフレンドに表示* をオフにします。フレンドの横の *招待* を押すとネット対戦ゲームを選べます。ボードゲームならふたり専用のルーム、Doom のゲームならそのロビーが開きます。ゲームはすぐにあなたの側で開き、フレンドには通知とメニュー上部の *承認* が届きます。招待の有効期間は 10 分です。招待できるのは、ネット対戦ゲームがブラウザーで開く環境です（Desktop の内蔵ブラウザーまたはブラウザーウィンドウ）。
- **チャット。** フレンドと 1 対 1、フレンドのグループ、またはワンクリックでフレンド全員のグループ。Arcade のパネルで直接書き込むか、サイトのチャットページを開きます。メッセージは Arcade のサイトに保存され、暗号化はされません — パスワードやキーは書き込まないでください。
- **アバターとメッセージの通知。** *アカウント* で 24 種類の既成アバターから 1 つを選びます。チャットはそれを表示するだけで、アバターがなければあなたの @ニックネームの最初の文字が表示されます。グループの画像は、グループのオーナーが同じ 24 種類から選びます。GitHub のプロフィール画像がほかの人に表示されることはありません。フレンドからメッセージが届くと、左下にすべてのウィンドウより手前にカードが表示されます（Windows）。macOS と Linux ではシステム通知になります。カードをクリックするとそのチャットが開きます。
- **サインアウト** するとこのコンピューターでの同期が止まります。**アカウントを削除**（2 回押す）すると、サイトからアカウントと設定が消去されます。

## ノートとプロジェクトボード

どちらもメニューの *仕事* セクションにあります。

- **ノート。** ページとサブページ。`# ` で始まる行は見出し、`- ` は項目、`- [ ] ` は押すとチェックが付くチェックリストの項目になります。このコンピューターに保存されます — 最大 200 ページ、1 ページあたり 20,000 文字まで。
- **Claude も書き込める。** *Claude に渡す* でページを Claude に渡すか、Arcade に何か書き留めるよう Claude に頼むだけです。Claude が使う `mcp__arcade__notes` ツールは、ノートだけを変更し、何も削除しません。Claude の編集が気に入らなければ、*Claude が書き換える前の本文に戻す* を押します。
- **Notion や別のアプリ** — Claude のコネクタ経由なので、Arcade にキーやパスワードは不要です：*Notion に送る*、*別のアプリへ*、*Notion などのアプリから取り込む*。リンクしたページは、そのアプリ側で更新することも、そこからもう一度取り込むこともできます。
- **音声。** システムの音声入力（Windows では Win+H、macOS では Fn を 2 回）で Claude の入力欄に話し、*Claude の入力欄から取り込む* を押すと、文字がページの末尾に移ります。
- **プロジェクトボード。** 列（*やること*、*作業中*、*完了*、または自分で作った列、最大 8 つ）とカード。カードは本文とチェックリストを持つノートのページです。カードを押すと選択され、矢印キーで移動できます。もう一度押すと開きます。Claude もボードを扱えます：*Claude に渡す* を押すか、Arcade のボードにタスクを並べるよう頼んでください。
- **共有ボード。** @ニックネームでサインインしていれば、フレンドを選んで *共有* を押します。カード、列、ボード名は全員で同じになり、変更は数秒で反映されます。オーナーはフレンドを追加で招待したり、メンバーを外したり、サイトからボードを削除したりできます。誰でも抜けられます。何が起きても、全員の手元に自分のコピーが残ります。自分の共有ボードは 3 つまで、1 つのボードに 20 人、カード 200 枚まで。

## 自分のゲーム

- **`/arcade-add <ファイル>`** で NES、メガドライブ、マスターシステムの ROM（4 MB まで）を追加できます。プラグインはコピーを `~/.claude/arcade` に保存し、どこにもアップロードしません。
- **PlayStation のディスクと Doom の WAD**（たとえば自分の `doom.wad`）は、Arcade ウィンドウの **自分のファイルを開く** から。そのブラウザーの中だけに保存されます。

権利を持っているファイルだけを追加してください。

## 設定

`/arcade` メニューの *その他* セクションにある **設定** を開きます：

- **メインメニューのセクション** — *その他* 以外のセクションを表示・非表示にできます。非表示にしたセクションは、ここで戻すまでメニューから完全に消えます。Arcade を初めて開いたときにも同じ選択ができます。
- **言語** — 13 言語から選択（メニューの 🌐 からも直接）。
- **ゲームを開く場所** — ここ（パネル）、ブラウザーウィンドウ、または特定のブラウザー。Claude Desktop では Claude の内蔵ブラウザーかブラウザーウィンドウ。
- **グラフィック**（ターミナル） — 画像を表示できるターミナル（kitty、Ghostty、Rio）ではピクセル、それ以外ではテキストブロック。
- **パネルサイズ** — 通常または全幅。
- **エージェントが完了したとき** — バナーを出してプレイ継続、バナー付きで一時停止、またはすぐエージェントに戻る。
- **エージェントが許可を求めたとき** — 同じ 3 つの選択肢。
- **ブラウザーが開いたとき**（Claude Desktop） — ブラウザーが高さいっぱいに使えるよう Arcade のメニューを閉じる、またはメニューをブラウザーの上に残す。
- **視聴中にエージェントが完了したら**（Claude Desktop） — Arcade が動画、配信、TikTok、記事、エピソードのために開いたタブを閉じて、Claude との会話を再び目の前に戻す、または知らせるだけ。
- **ウィンドウでプレイ中の通知。**
- **メッセージの通知** — フレンドがチャットに書き込むと、左下にカードを表示します（macOS と Linux ではシステム通知）。
- **キーテストとキー割り当て**（ターミナル）。
- **利用規約とプライバシー** — サイトの利用規約とプライバシーポリシーを、いつものブラウザーで開きます。

## プラグインがあなたのコンピューターで行うこと

Arcade は、Claude Code がプラグインに与える権限の範囲で Claude Code の中で動きます。コードはすべてこのリポジトリにあり、`claude plugin validate ./mod` を実行すると、フックしているイベントと行っている呼び出しがすべて一覧表示されます。要点は次のとおりです：

- **エージェントのツール。** Arcade は、ツールの開始と終了、エージェントが許可を求めたタイミングを把握し、それによってバナーを出すタイミングを決めます。エージェントのツール呼び出しを変更したりブロックしたりすることはありません。Arcade が自分で許可するのは 2 種類の呼び出しだけで、それも Claude Code が本来あなたに確認する場合に限られます：ノートだけを変更し何も削除しない `mcp__arcade__notes` と、パネルで押したゲームを Desktop の内蔵ブラウザーで開くことです。許可・拒否のルールはそのまま適用されます。
- **エージェントの中断。** Claude Desktop のみで、エージェントの作業中に内蔵ブラウザーで何かを開いたときに起こります。Desktop はプラグインが自分でブラウザーを開くことを許していないためです。Arcade は実行中のツールが終わるのを待ち（10 秒たつと中断しますが、許可の確認が表示されている間は待ちます）、エージェントを止めて、ページを開いてから作業に戻るよう Claude に頼みます。これを避けたい場合は、*設定 → ゲームを開く場所* でブラウザーウィンドウを選んでください。
- **会話。** トピックのために、あなた自身のセッション内の Haiku が会話の最後の数千文字を受け取ります。これは Claude の使用量に含まれます。Arcade のサイトが会話を見ることはありません。Arcade が入力欄に書き込んだり送信したりするのは、あなたが頼んだとき（たとえばノートの *Claude に渡す*）か、上で説明したようにページを開くときだけです。
- **起動するプログラム。** Arcade ウィンドウ用のブラウザー（Windows では `%LOCALAPPDATA%\claude-arcade` の専用プロファイル付き）、通知（Windows では PowerShell、macOS では `osascript`、Linux では `notify-send`）、インストール済みブラウザーの確認（Windows）または OS の確認（`uname`）。
- **ファイル。** 書き込むのは `/arcade-add` で追加した ROM だけで、保存先は `~/.claude/arcade/roms` です。読み込むのは、指定されたファイル、そのコピー、プラグイン自身のファイルだけです。設定、ノート、お気に入りは Claude Code のプラグイン用ストレージに保存されます。
- **環境変数。** `HOME` または `USERPROFILE`、`LANG`、`LC_ALL`、`LC_MESSAGES`、`LOCALAPPDATA`、`OS` を読み取りますが、どれも変更しません。
- **ネットワーク。** プラグイン自体が通信するのは、Arcade のサイト（`agent-arcade.fefaodessa.workers.dev`）、YouTube チャンネルの RSS フィード、表示するブログやポッドキャストのフィードだけです。Desktop のパネルの画像（Twitch のアバターなど）は、それぞれのサービスから直接読み込まれます。ゲーム、本、動画は、ブラウザーで開いたページが読み込みます。

## プライバシー

詳しくはサイトの[プライバシーポリシー](https://agent-arcade.fefaodessa.workers.dev/privacy)と[利用規約](https://agent-arcade.fefaodessa.workers.dev/terms)にあります。プラグインでは *設定 → 利用規約とプライバシー* から開けます。要点は次のとおりです：

- 広告なし、アナリティクスなし、トラッキングなし。アナリティクスが組み込まれていたゲームからは取り除いています（各ゲームの `NOTICE` を参照）。
- 自分の ROM、WAD、本、音声ファイルが、自分のマシンやブラウザーの外に出ることはありません。
- 本とオーディオブックの一覧、および Project Gutenberg の本は Arcade のサイトを経由します。サイトはそれらを Project Gutenberg、Wikisource、archive.org から取得し、Cloudflare のキャッシュにだけ保持します（一覧は 6 時間、本は 1 週間）。Wikisource のページと LibriVox の録音は、ウィンドウがそれぞれのサイトから直接読み込みます。
- オンラインプレイは Cloudflare 上の Arcade サーバーを経由します。メッセージはルーム内のプレイヤー間で中継されるだけで保存されません — ただし、あとで戻れるようにボードゲームの手は保存されます。1 か月放置された対局は削除されます。
- トピックは自分の Claude Code セッション内で Haiku が提案します。Arcade のサイトが会話を見ることはなく、*自分のトピック* を使ったときに短い英語の検索クエリが届くだけです。記事のアドレスは `#` の後ろに置かれるため、Arcade のサーバーには届きません。
- *自分のトピック* の検索は YouTube API Services を経由し、動画は YouTube 自身のプレーヤーで再生されます。そのため [YouTube 利用規約](https://www.youtube.com/t/terms)と [Google プライバシー ポリシー](https://policies.google.com/privacy)も適用されます。表示する最大 6 本の動画は、自分のセッション内の Haiku がタイトルと短い説明から選びます。Arcade のサイトは検索結果を共有キャッシュに 1 日保持します。
- サインインすると、サイトは同期した設定、お気に入り、@ニックネーム、フレンド、チャット、共有ボードを保存し、ゲームへの招待を 10 分間保存します。誰がオンラインかはメモリ上に 1 分半だけ保持します。セッションキーは Arcade のサイトにだけ送られます。
- ノートは自分のコンピューターに残ります。共有ボードはチャットと同じく Arcade のサイトに保存され、暗号化はされません。ページが Notion や別のアプリに送られるのは頼んだときだけで、その際も自分の Claude のコネクタを経由します。
- 不具合の報告に含まれるのは、本文、Arcade のバージョン、開いている環境、インターフェースの言語、OS だけです。サインインしていなければ署名なしで送られ、サイトはアドレスを一切保存しません。
- 一部のゲームは、こちらから求めたときだけインターネットにアクセスします — たとえば OpenTTD の任意のアンケートや *Online Content* ボタンです。

## フィードバック

不具合を見つけたら、いちばん早いのは Arcade から直接送る方法です：**その他 → 🐞 不具合を報告**。何が起きたかを書けば、バージョン、環境、言語、OS とともに Arcade の作者に直接届きます。

## 開発者向け

```
mod/     Claude Code プラグイン（フック、パネル UI、テスト）
site/    Cloudflare Workers 上のサイト：カタログ、Arcade ウィンドウ、ネットワークルーム、アカウント、フレンド、チャット、不具合の報告
tools/   ビルド用ツール：翻訳、heretic-wasm
.github/ doom-wasm、heretic-wasm、OpenTTD、ScummVM をブラウザー向けにビルドする GitHub Actions
```

- リポジトリからプラグインを起動：`claude --plugin-dir ./mod`
- プラグインのテスト：`claude plugin validate ./mod`、続いて `mod/` で `claude plugin test`
- サイトのテスト：`site/` で `npm test`。ビルド：`node build.mjs`。デプロイは Cloudflare Workers Builds により `main` から自動で行われます。
- 作業は `main` で行い、プルリクエストも `main` に送ってください。デフォルトブランチ `plugin` は `site/` を除いた `main` のコピーで、プッシュのたびに GitHub Action が更新します。プラグインのマーケットプレイスはリポジトリ全体ではなくこのブランチをダウンロードします。
- 翻訳：`node tools/i18n/collect.mjs`、続いて `node tools/i18n/check.mjs` — [tools/i18n/README.md](tools/i18n/README.md) を参照。

詳しいドキュメント（ロシア語）：[mod/README.md](mod/README.md) — プラグイン、[site/README.md](https://github.com/ArbakovMaxim/agent-arcade/tree/main/site/README.md) — サイト、ゲームの追加、ネットワークプレイ。
