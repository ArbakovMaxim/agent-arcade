# Arcade — Claude Code 里的任务看板、笔记、团队聊天和游戏

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md) · **中文** · [한국어](README.ko.md)

> **Beta 版（0.39）。** 这里介绍的一切都能正常使用，每天都有人在用；之后的变化主要在细节上。非常欢迎报告错误 — 见[反馈](#反馈)。

Arcade 是一个 [Claude Code](https://claude.com/claude-code) 插件，把它变成一个小小的工作台：项目看板上的卡片由 Claude 一张接一张地处理，甚至可以在多个会话里同时进行；Claude 和你一起记的笔记本，所有打开的会话共用；日历；还有给团队用的共享看板和聊天。等待的时候也有事做：当智能体忙碌超过 10 秒，提示符上方会出现一行小字 *“玩一会儿吗？”*。你可以玩游戏 — NES、Sega、PlayStation、Doom、国际象棋等等 — 读一本书，听有声书或播客，或者观看与智能体当前工作主题相关的视频。智能体一完成工作或需要你授权，Arcade 就会立刻告诉你，什么都不会错过。

目录中的一切都是免费的：游戏采用开放许可，书籍和有声书属于公有领域。你还可以和同样在等待智能体的其他人联网对战，并和好友聊天。

## 功能

- **笔记本与项目看板。** 页面、子页面和清单，Claude 也能帮你记；还有带列和卡片的看板。*交给 Claude* 会把页面或卡片交给 Claude：它会勾掉已完成的项目，并把结果写在上面。页面或卡片的文字会带格式显示，并有 *编辑* 和 *复制* 按钮。所有打开的 Claude Code 会话共用一个笔记本，因此每个会话都可以从同一块看板上领自己的卡片。与好友共享看板，大家就在同一块看板上协作。通过 Claude 的连接器把页面发送到 Notion 或其他应用，或从那里导入；在 Claude 输入框中听写，再把文字移到页面上。
- **Claude 逐张处理你的看板。** *排队交给 Claude* 会把第一列的卡片逐张交给 Claude：上一张进入 *已完成* 后才交出下一张，Claude 提出问题或卡片没做完时队列就会停止。卡片可以设截止日期，并显示在日历中；在共享看板上，每个人都能看到谁领取了哪张卡片。通过 Claude 的连接器，把 GitHub、Linear、Jira 或其他跟踪器中的 issue 作为卡片导入看板，再把结果以评论形式发回去。*今日总结* 会生成一页站会内容 — 交给 Claude 的、已完成的、进行中的 — 可以发到团队的聊天里。
- **提示词。** 反复输入的请求可以变成一键模板：按一下，它就会发给 Claude，和 *交给 Claude* 一样；*放入输入框* 则让你先补充完整。与好友共享模板集，整个团队就有相同的提示词。Claude 也能保存模板：“把这个存为 Arcade 里的提示词”。
- **今天。** *工作* 中的第一个磁贴把等你处理的事集中到一个屏幕：等待许可或回答的会话（带选项的问题可以当场回答）、今天的日程、今天到期或已逾期的卡片、你在共享看板上领取的卡片、未读聊天，以及一行 Claude 限额。
- **智能体。** *工作* 中的 *智能体* 按文件夹列出这台电脑上所有使用 Arcade 的 Claude Code 会话：工作中、后台工作中（Claude 的子智能体还在运行）、等待授权、已完成这一轮还是空闲，持续了多久，以及它的卡片和在队列中的位置。当其他会话中的 Claude 提出带选项的问题时，你可以直接在它的卡片里用按钮回答。当其他会话请求授权或提出问题时，你自己的面板中会弹出提示。一块看板的队列可以同时在多个会话中运行，两个会话不会拿到同一张卡片。每张卡片还会显示该会话的 git 分支和未提交的文件，两个会话改同一个文件时会给出提醒。
- **用量。** *工作* 中的 *用量* 磁贴显示 Claude 的限额窗口 — 5 小时、一周和消费限额 — 以及百分比、进度条和各自的重置时间，还有本会话和其他会话的上下文与费用。数字来自 Claude Code 本身。如果看板队列进行到一半时限额用完，一个按钮就能在重置后继续它。
- **日历。** 在 Desktop 中，一个月由大小相同的日期方块组成，每个日程都有一个对应颜色的圆点；在终端和 VS Code 中则是近期日程列表。一行就能添加日程，比如“fri 9:30 standup”，还可以设为每天、工作日、每周、每月或每年重复。颜色和提醒时间可以从列表里选，也可以自己写，比如“45 min before”或“the day before at 20:00”；提醒以系统通知的形式到达。看板卡片的截止日期也会显示在这里。Claude 也能添加和修改日程：“周五 15:00 加一个电话会议”。到了日程时间，Arcade 可以把任务交给 Claude：看板队列、一张卡片、一个模板或你自己写的文字。
- **好友与聊天。** 可选的 GitHub 登录让你在所有电脑上保持相同的设置，并获得一个 @用户名；通过准确的用户名添加好友，查看谁在线，共享看板，邀请他们一起玩，进行一对一或群组聊天。
- **了解智能体的状态。** 当智能体完成工作或请求授权时，游戏上方会出现横幅 — 继续玩、暂停，或直接返回智能体（具体行为在设置中选择）。在 Claude Desktop 中，它还可以关闭你正在观看的标签页，让对话重新回到你面前。
- **自动出现。** 智能体工作 10 秒后，Arcade 会在提示符上方推荐一款游戏 — 也可以在设置里改成更晚出现或不出现；除非你要求，它绝不会抢走焦点。
- **跨会话跟随。** 让 Arcade 面板保持打开，之后每个新的 Claude Code 会话都会自动打开它；手动关闭后，它就保持关闭。
- **一个菜单，六个分区。** *开始游戏*、*阅读与收听*、*观看*、*社交*、*工作* 和 *更多* — 不需要的分区可以折叠。最上方是：*继续* 上一款游戏、*搜索* 和 *收藏*。第一次打开 Arcade 时，你可以选择要显示哪些分区。
- **61 款免费游戏**，涵盖 NES（Dendy）、Sega Mega Drive、Master System、PlayStation，以及包含街机、射击、竞速、策略、冒险和棋类游戏的 *游戏* 标签页。
- **阅读与收听。** 30 种语言的经典书籍和 LibriVox 有声书，直接来自 Project Gutenberg、Wikisource 和 LibriVox；还有与智能体工作主题相关的最新文章和播客节目。
- **观看。** 与智能体工作主题相关的最新 YouTube 视频，以及 Twitch：你自己的频道，和关于编程、科技、科学与复古游戏的直播。还有 TikTok：TikTok 官网上的 *“推荐”信息流* 和搜索（需要你自己登录）。
- **NES 和 Flappy Arcade 直接在 Claude Code 里运行** — 终端、VS Code 和 Claude Desktop 都可以。其他内容在浏览器窗口中打开；在 Claude Desktop 中默认使用 Claude 的内置浏览器（射击游戏仍在浏览器窗口中打开：内置浏览器无法捕获鼠标）。
- **联网对战。** 通过网络进行的双人主机游戏、Doom 死亡竞赛和合作模式，以及与真人或电脑对弈的国际象棋、围棋、跳棋和黑白棋。
- **“谁在线等待”。** 有人在等待对手时，Arcade 会在 Claude Code 中显示，并附带 *加入* 按钮。
- **搜索与收藏。** 一次搜索即可覆盖游戏和 Twitch 频道，结果按分区和类型分组；用 ☆ 标记游戏，即可保存到 *★ 收藏*。
- **你自己的游戏。** 添加你拥有的 ROM；它们只保存在你的电脑上。
- **13 种界面语言：** English、Русский、Українська、Español、Français、Deutsch、Português、Italiano、Polski、Türkçe、日本語、中文、한국어 — 根据系统或浏览器语言自动选择，默认英语。

## 安装

需要 **Claude Code 2.1.275 或更高版本**。*用量* 需要能向插件报告限额的 Claude Code（已在 2.1.302 和 2.1.316 上验证）；在更旧的版本中，这个页面会说明这一点，Arcade 的其他功能照常可用。

在终端中运行两条命令：先添加 Arcade 的插件市场（就是本仓库），再从中安装插件：

```
claude plugin marketplace add ArbakovMaxim/agent-arcade
claude plugin install arcade@agent-arcade
```

或者在 Claude Code 会话中：

```
/plugin marketplace add ArbakovMaxim/agent-arcade
/plugin install arcade@agent-arcade
```

插件会安装到所有会话和应用中。VS Code 扩展没有 `/plugin` 命令 — 请在终端中安装，扩展会在新对话中加载插件。

**更新：**

```
/plugin marketplace update agent-arcade
/plugin update arcade@agent-arcade
```

然后重启 Claude Code。插件市场只下载插件本身（几 MiB，不含网站），所以更新只需几秒。已经安装了 Arcade 的话无需任何操作：下次更新时插件市场会自动切换。

如果 `/plugin update` 显示 *already at the latest version*，但 Arcade 已经发布了新版本，说明插件市场没有刷新。在终端中运行 `claude plugin marketplace update agent-arcade` 可以看到原因。如果显示 *timed out*，就给克隆留出 10 分钟：

```
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000 claude plugin marketplace update agent-arcade
```

PowerShell 中：`$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000; claude plugin marketplace update agent-arcade`。然后再次运行 `/plugin update arcade@agent-arcade`。

**卸载：** `/plugin uninstall arcade@agent-arcade`

## 使用方法

- **`/arcade`** 随时打开菜单。
- 让面板保持打开，新会话就会自动打开它：终端中在启动时打开，Desktop 和 VS Code 中在连接到会话时打开；键盘焦点仍留在输入框中。手动关闭（关闭按钮或 Esc）后，它就不再自动打开，直到你再次打开它。
- 当智能体工作超过 10 秒，提示符上方会出现 *“玩一会儿吗？”*：**`1`** — 在这里（面板中）玩；**`2`** — 在浏览器窗口中（如果可用）；**`3`** — 现在不玩（接着可选择多久不再询问：5 分钟、10 分钟、直到 Claude 重启（在这台电脑的所有会话中）或仅这一次）。在“设置 → 通知”中可以选择它何时出现（10 秒到 5 分钟），也可以关闭它。
- 用方向键或 Tab 选择，Enter 打开；也可以使用鼠标。每款游戏下方都会显示操作方式。
- 当智能体完成工作或等待授权时，游戏上方会出现横幅：**返回智能体** 或 **继续玩**。

## 笔记本与项目看板

两者都在菜单的 *工作* 分区中。

- **笔记本。** 页面和子页面；以 `# ` 开头的行是标题，`- ` 是条目，`- [ ] ` 是清单项，按一下即可勾选。保存在这台电脑上 — 最多 200 个页面，每页最多 20,000 个字符。
- **编辑与复制。** 在 Desktop 和 VS Code 中，页面或卡片的文字会带格式显示（标题、列表、清单），在终端中则逐行显示。*编辑* 会在原处打开文本框：Enter 保存，*取消* 放弃修改；在此期间 Claude 或其他会话做的修改也会出现在文本框中。*复制* 会把整个页面放进剪贴板 — 在 Desktop 的面板中只能在输入框里选中文字，所以要复制页面就用它。
- **Claude 也能记。** *交给 Claude* 会把页面交给 Claude，或者直接让 Claude 在 Arcade 里记点东西。Claude 使用 `mcp__arcade__notes` 工具，它只修改笔记本，不删除任何内容。如果不喜欢 Claude 的修改，可以按 *恢复 Claude 修改前的文字*。
- **Notion 和其他应用** — 通过 Claude 的连接器，所以 Arcade 不需要任何密钥或密码：*发送到 Notion*、*发到其他应用*、*从 Notion 或其他应用导入*。已关联的页面可以在应用中更新，也可以重新从应用导入。
- **语音。** 用系统自带的听写（Windows 上按 Win+H，macOS 上按两下 Fn）在 Claude 输入框中输入，然后按 *从 Claude 输入框取用* — 文字会移到页面末尾。
- **项目看板。** 列（*待办*、*进行中*、*已完成* 或自定义的列，最多 8 列）和卡片；卡片就是带文字和清单的笔记本页面。按一下卡片即可选中并用方向键移动，再按一次打开。Claude 也能管理看板：按 *交给 Claude*，或者让它把任务排到 Arcade 的看板上。
- **共享看板。** 用 @用户名登录后，勾选好友并按 *共享*：所有人的卡片、列和名称都一样，修改几秒内就会同步。所有者可以邀请更多好友、移除成员，并从网站上删除看板；任何人都可以退出；无论发生什么，每个人都会保留自己的一份副本。自己的共享看板最多 3 个，每块看板最多 20 人、200 张卡片。
- **多个会话同时使用。** 这台电脑上所有打开的 Claude Code 会话共用一个笔记本及其看板：一个会话添加、修改或勾选的内容，其他会话几秒内就能看到，因此每个会话都可以负责同一块看板上的一张卡片。
- **排队交给 Claude。** 在看板上按 *排队交给 Claude*，Claude 会收到第一列的第一张卡片；如果看板多于两列，这张卡片会被移到第二列。Claude 结束这一轮时，如果这张卡片已在最后一列，下一张会自动交出，每次最多 10 张。当 Claude 提出问题、这一轮被中断或出错结束、卡片不在最后一列，或者你给 Claude 发了别的内容时，队列就会停止 — 之后由你决定。请求授权不会让队列停止：只要授权已给出（由你或自动模式），且卡片在最后一列，下一张就会交出。*停止队列* 会让 Claude 做完当前卡片，但不再交出下一张。在共享看板上，别人已领取的卡片会被跳过。队列可以同时在多个会话中运行 — 见[智能体](#智能体)。如果队列进行到一半时 Claude 的限额用完，可以在重置后继续 — 见[用量](#用量)。
- **卡片间检查。** 在看板页面的 *卡片间检查* 里填一条命令，比如 `npm test`；卡片也可以在 *此卡片的检查* 里有自己的命令。Claude 结束一轮时，如果卡片已在最后一列，队列会先在会话文件夹里运行这条命令（最长 10 分钟），再交出下一张。退出码为 0，下一张就交出。否则队列停下，卡片带着 *检查未通过* 的标记回到第二列，Claude 会收到输出的末尾，修好后再把卡片移过去；你再次启动队列时，Arcade 会先检查这张卡片。结果显示在看板上和 *今日总结* 里。如果队列在多个会话里运行，由做这张卡片的会话来运行检查。命令像 Claude Code 的钩子一样不经权限确认就运行，只保存在这台电脑上——不在笔记本里，也不在共享看板上——Claude 和看板成员都改不了它。没有命令时，队列和以前一样。
- **截止日期。** 卡片的 *截止日期* 字段可以填“fri”“tomorrow”“20.11”或“2026-11-20”。日期显示在看板上的卡片下方 — 过期而卡片未完成时会变成警示色 — 也会显示在日历中；当天 9:00 日历会提醒你，除非卡片已经在最后一列。Claude 也能设置截止日期。
- **谁领取了卡片。** 在共享看板上，*交给 Claude* 会把卡片标记为你的，所有人都会在卡片下方看到“领取人 @handle”。如果别人已经领取，Arcade 会先告诉你；再按一次，就仍会交给你自己的 Claude。*释放卡片* 可以取消领取。
- **来自跟踪器的 issue。** 在看板上选择跟踪器（GitHub、Linear、Jira 或 *其他跟踪器*），并填写从哪里导入：`owner/repo`、团队或项目的键，或者一个链接。Claude 会通过该跟踪器的连接器读取最多 20 个未关闭的 issue，并把还不在看板上的添加为卡片。在这样的卡片上，带跟踪器名称的 *结果发到* 按钮会让 Claude 在 issue 下发一条简短评论，说明做了什么；它不会关闭 issue，也不会更改其状态。Arcade 本身从不与跟踪器通信，也不保存任何密钥：一切都通过你在 Claude 中添加的连接器完成 — GitHub、Linear、用于 Jira 的 Atlassian、Asana、ClickUp、monday.com 等。如果没有连接器，Claude 会直接说明，并告诉你在哪里添加。
- **今日总结。** 看板列表下方和笔记本中的这个按钮会生成一页“总结 DD.MM”：今天交给 Claude 的、已完成的 — 移到最后一列的卡片、已勾选的项目 — 以及仍在进行中的。可以把它交给 Claude、编辑，或者发到聊天。
- **发到聊天。** 登录后，*发到聊天* 可以把任意页面以文字形式发到你最近的某个聊天中，标题和清单标记都会保留。

## 提示词

菜单 *工作* 分区里的一个磁贴：你自己的提示词模板，每个按一下就发给 Claude。

- **模板。** 模板就是按钮上的名称，加上要发给 Claude 的文字。在 *新模板* 中输入名称，再输入文字；Enter 保存。模板放在模板集里：第一个模板进入 *我的提示词*，*新模板集* 可以再建一个。模板可以重命名、编辑、用 *↑ 上移* 和 *↓ 下移* 调整位置，删除要按两次。
- **按一下。** 按下模板，它的文字就会原样发给 Claude，和 *交给 Claude* 一样：Claude 空闲时立即发送；Claude 正忙时，模板会在输入框里等着，直到你发送。*放入输入框* 会把它加到你已在输入框里输入的内容后面，不发送，方便你补充完整。每个模板下方显示其文字的第一行；✎ 打开编辑。
- **Claude 也能保存。** 说一句“把这个存为 Arcade 里的提示词”，Claude 就会用 `mcp__arcade__notes` 工具添加一个模板。
- **共享模板集。** 用 @用户名登录后，打开 *模板集设置*，勾选好友并按 *共享*：所有人的模板和名称都一样，修改几秒内就会同步。好友的共享模板集会自动出现在你的 *提示词* 中。和 [共享看板](#笔记本与项目看板) 一样，所有者可以邀请和移除成员，任何人都可以退出，每个人都会保留自己的一份副本。共享模板集计入你自己的 3 个共享看板。
- **不是命令。** 模板是 Arcade 面板中的按钮，不是 Claude Code 命令：斜杠命令和技能照常可用。模板和笔记本一起保存在这台电脑上，计入笔记本的 200 个页面。

## 日历

在菜单的 *工作* 分区里。和笔记本一样，日历保存在这台电脑上 Claude Code 的插件存储中，所有打开的会话共用。

- **月和日。** 在 Desktop 中，是由大小相同的日期方块组成的月份网格，带箭头和 *今天*：上方是日期，下方是每个日程对应颜色的圆点（最多三个，之后显示“+N”）。选中的日期边框高亮，今天带底色。网格下方是选中日期的日程，再往下是未来 30 天的 *近期日程*，以日程颜色的卡片显示。在终端和 VS Code 中则是 *近期日程* 列表。
- **一行添加日程：**“fri 9:30 standup”“tomorrow 15:00 call”“12.11 review”“2026-11-20 10:00 demo”。不写日期就记到网格中选中的那天（终端中为今天），不写时间就是全天。表示日期的词支持英语和俄语。
- **重复。** 不重复、每天、工作日、每周、每月或每年；日程所在的那天就是重复的开始。也可以一行写出：“every friday 10:00 retro”“on weekdays 9:30 standup”。
- **颜色。** 蓝、绿、黄、橙、红、紫、粉、灰；默认蓝色。
- **提醒。** 从列表中选择：开始时，提前 5、10、15 或 30 分钟，提前 1 或 2 小时，提前一天、两天或一周；全天日程可选当天 9:00、8:00 或 7:00，前一天 21:00、18:00 或 9:00，提前两天或一周的 9:00。也可以用英语或俄语写自己的时间：“45 min before”“at 14:30”“the day before at 20:00” — 不晚于开始，也不早于一周前。手机上的 Claude 应用没有列表，用按钮依次切换选项。
- **通知。** 只要有任意一个 Claude Code 会话开着，提醒就会以系统通知和简短提示的形式到达；由一个会话显示，而不是全部。Claude Code 关闭期间错过的提醒，如果日程在一天之内，会在下次启动时显示为 *错过*。
- **Claude 也能管理**，用只修改日历的 `mcp__arcade__calendar` 工具：“周五 15:00 加一个电话会议”“我明天有什么安排？”“把演示改成红色”。
- **卡片截止日期。** 设了截止日期的看板卡片会在那天显示为全天日程，卡片进入最后一列后标为 *已完成*；要修改，请在卡片上改。
- **定时：交给 Claude 的任务。** 在日程中，*交给 Claude* 用来选择 Claude 在日程时间收到什么：看板队列、一张卡片、[提示词](#提示词)中的模板或你自己写的文字；全天日程则在 9:00。重复照常有效。Claude 也能设置：“每个工作日 9:00 把‘发布’看板的队列交给 Claude”。
- **在哪里运行。** 日程会记住设置它时所在的文件夹；任务会交给该文件夹中已打开的 Claude Code 会话，只交给其中一个。Claude 正忙时，任务会等这一轮结束。*在此文件夹中运行* 会把它改到当前会话的文件夹。
- **错过的任务。** 如果该文件夹中没有打开的会话（Claude Code 已关闭或电脑在休眠），任务不会自己补运行：会出现简短提示，日历顶部会显示 *错过*，并带有 *立即运行* 和 *不运行*。错过超过一天的任务会被静默跳过。
- **它不保证什么。** 只有在 Claude Code 开着、电脑没有休眠时才有效；Arcade 不会唤醒电脑，也不会启动 Claude Code。任务按会话当前的权限模式运行，Arcade 不会赋予新的权限：不在 Auto 模式时，Claude 可能会等待你的授权。
- **与其他定时工具相比。** Claude Code 有自己的定时方式：`/loop` 在当前会话中重复一个提示词，Desktop 的定时任务按计时器启动会话，云端定时任务即使你的电脑关机也会运行。Arcade 的定时围绕你的看板和日历：任务显示在月份网格中你的日程旁边，交给项目文件夹中已打开的会话，并且在终端、VS Code 和 Desktop 中用法相同。
- 它暂时还不与 Google 或 Apple 日历同步。

## 智能体

在菜单的 *工作* 分区里：这台电脑上使用 Arcade 的 Claude Code 会话，每个都以它的文件夹命名，你自己的会话标为 *本会话*。

- **每个会话在做什么。** *等待授权*、*等待回复*、*已完成这一轮*、*工作中*、*后台工作中 · 智能体：2* 或 *空闲*，持续了多久，以及它正在处理的卡片和在队列中的位置，例如 *队列：第 3 张，共 10 张*。*后台工作中* 表示 Claude 这一轮已经结束，但它启动的子智能体还在运行：*已完成这一轮*、对应的提示和队列中的下一张卡片都会等到它们结束。等待授权的会话排在最前面。在 Desktop 中每个会话是一张卡片，在终端和 VS Code 中是一行。关闭的会话不到一分钟就会消失。
- **按文件夹找到它。** Arcade 无法替你打开另一个会话；看文件夹名称就知道是哪个窗口或标签页。
- **在这里回答。** 当其他会话中的 Claude 提出带选项的问题时，它的卡片会以按钮显示问题和选项。只有一个问题时，第一次点击就会发送；有多个问题时，选好选项后点击 *回答*。一秒内，那个会话中的 Claude 就会收到回答，和在那里直接回答一样。授权请求也会显示，附带工具和命令，例如 *Bash: npm test*，但授权只能在那个会话本身中给出。
- **一个队列，多个会话。** 在每个会话中对同一块看板按 *排队交给 Claude*，空闲的会话就会领取下一张卡片；两个会话不会拿到同一张卡片。加入的会话会说明这一点：*此看板的队列已在会话“api”中运行*。每个会话按同样的规则停止自己的队列 — Claude 提出问题、卡片没做完、这一轮被中断、你提出别的请求 — 每次最多交出 10 张卡片。*停止队列* 只停止本会话；*全部停止* 会停止所有会话，每个会话都会做完当前的卡片。卡片下方，看板会显示谁在处理它：*由会话“api”处理*。
- **同一文件夹。** 如果已在队列中的某个会话在同一文件夹中工作，Arcade 会提醒两个会话可能修改同一批文件，只有再按一次 *排队交给 Claude* 才会加入。使用单独的文件夹或 git worktree 更稳妥。
- **改了什么。** 在 git 文件夹中，会话卡片上有一行，比如 *分支 landing · 已改动文件：4 · 未提交*，如果有未推送的提交，还有 *未推送的提交：2*；点一下，就会展开文件列表，带新增和删除的行数。两个会话改同一个文件时，两张卡片都会提示 — *会话“api”也在编辑 app.js*；同一文件夹里的会话共享改动，Arcade 会说明分不清是谁的。你自己的卡片上有 *交给 Claude：检查改动*：Claude 会看一遍未提交的改动，告诉你哪些值得修改，不会提交、回滚，也不会放进 stash。其他会话的改动只做显示。每个会话在启动时和每一轮结束时，在自己的文件夹里读取 git — 只读，没有定时器，不联网。
- **面板提示。** 当其他会话请求授权或提出问题时，你自己的 Arcade 面板中会弹出提示 *会话“api”正在等待授权* 或 *…正在等待问题的回答* — 没有声音，也没有系统通知。在 *设置 → 通知* 中可以关闭它，或打开这一轮完成时的提示（默认关闭）。
- **隐藏一个。** 点击其他会话旁的 ×，就会把它连同它的提示一起隐藏，直到你在下方的 *已隐藏的会话* 中把它恢复；正在等待授权或回答的已隐藏会话会在那里注明。隐藏的会话在所有会话中通用。
- **只留在这台电脑上。** 每个会话在 `~/.claude/arcade/agents` 中保存一个小文件，记录它的文件夹、状态和卡片、它在等待的问题或授权请求，以及供[用量](#用量)使用的上下文、费用和限额窗口；从 *智能体* 发出的回答会以小文件的形式放在旁边，交给那个会话；在 git 文件夹中，还记有分支和改动文件的名称及行数；不会向 Arcade 的网站发送任何内容。

## 用量

在菜单的 *工作* 分区里。数字来自 Claude Code 本身，和状态栏显示的一样：Arcade 自己不做统计。

- **限额窗口。** 5 小时、一周和消费限额 — 百分比、进度条和重置时间：*14:30 重置（还有 1 小时 20 分）*。进度条为蓝色，从 80% 起变黄，限额用完后变红。窗口属于账户，由它的所有会话共享，因此页面显示的是这台电脑上所有会话中最新的一次读数，以及它是几分钟前的。
- **没有窗口时。** 在 Claude 第一次回答之前，页面会说明：*Claude 第一次回答后显示。* 使用 API 密钥或通过网关时完全没有窗口 — 只有上下文和费用：5 小时和每周窗口属于 Claude 订阅（Pro、Max、Team、Enterprise）。
- **本会话和其他会话。** 上下文的占用 — 百分比和 token 数 — 以及会话开始以来的费用；下方是这台电脑上其他会话的上下文和费用。同样的数字也会显示在[智能体](#智能体)中它们的卡片上。
- **重置后的队列。** 如果在[看板队列](#笔记本与项目看板)进行到一半时 Claude 的这一轮中断了，而 Claude Code 显示某个窗口已到 100%，队列就会停下，并说明限额何时重置。*在 14:31 重置后继续队列* 会在重置一分钟后从同一张卡片继续；等待期间显示 *队列“发布”将在 14:31 继续。* 和 *不继续*。也可以事先标记看板，这样它的队列会自动继续，无需按钮。
- **仅在 Claude Code 开着时。** 只有开着的会话、且电脑没有休眠时，才能继续队列。如果 Claude Code 已关闭或电脑在休眠，*用量* 会说明：*限额重置后，队列“发布”没有继续：Claude Code 已关闭或电脑在休眠。* 如果正在等待的会话被关闭了，则显示 *限额重置后，队列“发布”没有启动：会话已关闭。* 按 × 可清除这条说明。
- **80% 和 90% 的提示。** 当某个窗口达到 80%，再达到 90% 时，Arcade 面板中会弹出提示 — 每个阈值在所有会话中只提示一次。可在 *设置 → 通知* 中关闭。
- **哪个 Claude Code。** 并非每个版本的 Claude Code 都会向插件报告限额 — 已在 2.1.302 和 2.1.316 上验证。如果你的版本不报告，页面会说明这一点，Arcade 的其他功能照常可用。

## 今天

菜单 *工作* 分区里的第一个磁贴：把整个 Arcade 里等你处理的事放在一个屏幕上。它自己不保存任何东西，一切都来自 Arcade 已经知道的信息。

- **等你处理。** 这台电脑上等待许可或回答的会话，等得最久的在最上面，和 [智能体](#智能体) 里一样。带选项的问题可以在这里直接按按钮回答；许可只能在那个会话里给。
- **日历上。** 今天的日程；已经过去的显示得更淡。按一下会在 [日历](#日历) 里打开。
- **截止日期。** 今天到期或已逾期、还不在最后一列的看板卡片，并附上看板名称；按一下打开卡片。
- **我的卡片。** 你在共享看板上领取、还没完成的卡片。
- **聊天。** 已登录时的未读聊天；按一下打开聊天。
- **用量。** 来自 [用量](#用量) 的一行，例如 *5 小时: 62%, 14:30 重置*；从 80% 起变黄。

空的区块会隐藏；没有等你处理的事时，屏幕会显示 *今天没有待办了。* 在 Desktop 中会话显示为卡片，在终端和 VS Code 中全部显示为文字行。

## 团队使用

小团队可以把任务放在 Arcade 里：一块共享看板，谁领了卡片，就把它交给自己的 Claude。

1. 每个人都安装 Arcade（Claude Code 2.1.275 或更高版本） — 见[安装](#安装)。
2. `/arcade` → **社交** → **使用 GitHub 登录**：GitHub 页面会在你的浏览器中打开；在那里确认后，再在 Arcade 页面上点击 *Sign in*（页面上的代码应与面板中的相同）。如果不成功，请选 *用代码登录*。
3. 取一个 @用户名 — 一键使用你的 GitHub 名称，或自己起一个。
4. 通过准确的 @用户名互相添加好友；对方接受即可。
5. **工作** → 新建看板 → 勾选队友 → **共享**。
6. 只为看板和聊天而来？第一次打开 Arcade 时，只保留 **工作** 和 **社交**。然后在 **设置 → 通知** 中按 **“玩一会儿吗？”提示行**，直到它显示 *关*：智能体工作时，提示符上方就不会再出现任何东西。

之后只需：打开看板，选一张卡片，按 **交给 Claude**。如果 Claude 空闲，卡片会立刻交给它；如果它正忙，卡片会留在输入框里，等你发送。Claude 会勾掉已完成的项目，把结果写在卡片上，看板上的所有人几秒内就能看到，也能看到谁领取了哪张卡片。给每张卡片设一个截止日期，它就会出现在你的日历里。一天结束时，用 *今日总结* → *发到聊天* 把你的站会内容发到团队聊天。聊天在 **社交** 中。

你自己同时运行多个 Claude Code 会话？在每个会话中对同一块看板按 *排队交给 Claude*：空闲的会话会领取下一张卡片，**工作** → **智能体** 会显示每个会话在做什么。

须知：共享看板和聊天保存在 Arcade 的网站上，且没有加密，所以不要在其中写密码或密钥。Arcade 只会获得你的 GitHub 个人资料名称和头像。自己的共享看板最多 3 个，每块看板最多 20 人、200 张卡片。*删除账户*（按两次）会让网站删除你和你的设置。

## 账户、好友和聊天

登录是可选的 — 不登录，其他一切照常可用。

- **使用 GitHub 登录**（在 *社交* 中）：GitHub 登录页会在你常用的浏览器中打开；在那里确认后，再在 Arcade 页面上点击 *Sign in* — 页面上的代码应与面板中的相同。如果通过浏览器登录不成功，请选 *用代码登录*：Arcade 显示一个代码，你在 GitHub 页面上输入它。Arcade 只会获得你的 GitHub 个人资料名称和头像 — 不会获得邮箱，也无法访问仓库。
- **同步。** 你的语言、按键、通知、面板大小、智能体发出信号时如何处理游戏、Desktop 中的浏览器选项、你的主题、Twitch 频道、收藏、折叠和隐藏的分区以及 Flappy Arcade 最佳成绩，会在你所有的电脑上保持一致。你自己的游戏、浏览器和图形模式则按电脑分别保存。
- **@用户名。** 一键使用你的 GitHub 名称，或自己起一个：4 到 32 个字符 — 拉丁字母、数字和 `_`。每天最多可以修改 5 次。
- **好友。** 通过准确的 @用户名添加好友：对方在自己那边接受请求后，你们就会出现在彼此的列表中。输入时没有任何建议，所以没人能借此浏览谁在使用 Arcade。拒绝和删除都不会通知对方。
- **在线状态与游戏邀请。** Arcade 菜单打开时，好友会看到你 *在线*，你也能看到他们；不想被看到，就在 *好友* 页面关闭 *向好友显示我在线*。好友旁边的 *邀请* 会列出联网游戏：棋类游戏会打开你们俩的专属房间，Doom 类游戏会打开它的大厅。游戏会立刻在你这边打开；好友会收到通知，并在菜单顶部看到 *接受*，邀请有效期 10 分钟。只有在联网游戏通过浏览器打开的地方才能邀请：Desktop 的内置浏览器或浏览器窗口。
- **聊天。** 与好友一对一聊天、好友群组，或一键创建包含所有好友的群组。直接在 Arcade 面板中写消息，或在网站上打开聊天页面。自己的消息可以通过旁边的 ⋮ 菜单编辑或删除；在网站上，右键单击也会打开同一个菜单。消息保存在 Arcade 的网站上，且没有加密 — 不要在其中写密码或密钥。
- **头像和消息通知。** 在 *账户* 中从 24 个现成头像里选一个，聊天只负责显示；没有头像时显示你的 @用户名的首字母。群组图片由群主从同样的 24 个中选择。你的 GitHub 头像永远不会展示给其他人。好友给你发消息时，左下角会在所有窗口之上弹出一张卡片（Windows），或显示系统通知（macOS、Linux）；点击卡片即可打开该聊天。
- **退出登录** 会停止这台电脑上的同步；**删除账户**（按两次）会让网站删除你和你的设置。

## 插件在你的电脑上做什么

Arcade 在 Claude Code 内部运行，拥有 Claude Code 给插件的权限。它的全部代码都在这个仓库里，`claude plugin validate ./mod` 会列出它挂接的每个事件和发出的每个调用。简单来说：

- **智能体的工具。** Arcade 能看到工具何时开始和结束、智能体何时请求授权 — 这样它才知道什么时候显示横幅。它从不修改或拦截智能体的工具调用。它自己只批准三类调用，而且只在 Claude Code 本来会询问你的时候：只修改笔记本、不删除任何内容的 `mcp__arcade__notes`，只修改日历的 `mcp__arcade__calendar`，以及在你于面板中按下游戏后，在 Desktop 的内置浏览器中打开它。你的允许和拒绝规则照常生效。
- **中断智能体。** 仅在 Claude Desktop 中、智能体工作时你在内置浏览器里打开内容才会发生：Desktop 不允许插件自己打开浏览器。Arcade 会等当前工具结束（10 秒后会中断它，但只要屏幕上有授权请求就一直等），然后中断智能体，请 Claude 打开页面后继续工作。如果想避免这种情况，请在 *设置 → 游戏打开方式* 中选择浏览器窗口。
- **你的对话。** 为了推荐主题，你自己会话中的 Haiku 会收到对话的最后几千个字符；这会计入你的 Claude 用量。Arcade 的网站永远看不到对话。只有在你要求时（例如笔记本中的 *交给 Claude*、你启动的 *排队交给 Claude* 中的下一张卡片，或设置了 *交给 Claude* 的日程到点时交出的任务），或者如上所述为了打开页面，Arcade 才会在输入框中写入或提交内容。
- **用量。** 每一轮结束后以及每隔半分钟，Arcade 会向 Claude Code 询问它自己对限额、上下文和费用的读数 — 也就是状态栏显示的内容。这不产生任何费用，也不计入你的 Claude 用量。
- **启动的程序。** 用于 Arcade 窗口的浏览器（在 Windows 上使用 `%LOCALAPPDATA%\claude-arcade` 中的独立配置文件）；通知（包括日历提醒）— Windows 上用 PowerShell，macOS 上用 `osascript`，Linux 上用 `notify-send`；检查装了哪些浏览器（Windows）或是什么系统（`uname`）。另外，为了 *智能体*，在每个会话自己的文件夹里、启动时和每一轮结束时运行只读的 `git`（`rev-parse`、`status` 和 `diff --numstat`）。另外，如果看板设了 *卡片间检查*，队列里的卡片到达最后一列时，会在会话文件夹里运行那条命令。
- **文件。** 它只写入你用 `/arcade-add` 添加的 ROM（位置是 `~/.claude/arcade/roms`），以及每个会话为 *智能体* 和 *用量* 留下的小标记和从那里发出的回答（位置是 `~/.claude/arcade/agents`）；只读取你指定的文件、这些副本、这些标记和它自己的文件。设置、笔记本、日历和收藏保存在 Claude Code 的插件存储中。
- **环境变量。** 读取 `HOME` 或 `USERPROFILE`、`LANG`、`LC_ALL`、`LC_MESSAGES`、`LOCALAPPDATA` 和 `OS`，不修改任何一个。
- **网络。** 插件本身只与 Arcade 的网站（`agent-arcade.fefaodessa.workers.dev`）、YouTube 频道的 RSS 订阅源，以及它展示的博客和播客的订阅源通信。Desktop 面板中的图片（例如 Twitch 头像）直接从这些服务加载。游戏、书籍和视频由你在浏览器中打开的页面加载。

## 隐私

详情见网站的[隐私政策](https://agent-arcade.fefaodessa.workers.dev/privacy)和[使用条款](https://agent-arcade.fefaodessa.workers.dev/terms)；在插件中位于 *设置 → 条款与隐私*。简而言之：

- 没有广告，没有分析，没有追踪。原本带有分析功能的游戏已将其移除（见每款游戏的 `NOTICE`）。
- 你自己的 ROM、WAD、书籍和音频文件绝不会离开你的电脑或浏览器。
- 书籍和有声书列表以及 Project Gutenberg 的书籍经由 Arcade 网站获取：网站从 Project Gutenberg、Wikisource 和 archive.org 取来，只保存在 Cloudflare 缓存中——列表六小时，书籍一周。Wikisource 页面和 LibriVox 录音由窗口直接从这些网站加载。
- 联网对战通过 Arcade 在 Cloudflare 上的服务器进行：消息只在房间内的玩家之间转发，不会保存 — 棋类游戏的走法除外，保存它们是为了让你可以回来继续；一个月无人动过的对局会被删除。
- 主题由 Haiku 在你自己的 Claude Code 会话中推荐；Arcade 的网站永远看不到你的对话 — 只有在你使用 *自定义主题* 时，才会收到一条简短的英语搜索查询。文章地址放在 `#` 之后，因此永远不会到达 Arcade 的服务器。
- *自定义主题* 的搜索经由 YouTube API Services，视频在 YouTube 自己的播放器中播放，因此 [YouTube 服务条款](https://www.youtube.com/t/terms)和 [Google 隐私权政策](https://policies.google.com/privacy)同样适用。最多 6 个视频由你自己会话中的 Haiku 根据标题和简短描述挑选；Arcade 的网站把搜索结果在共享缓存中保留一天。
- 登录后，网站会保存你同步的设置、收藏、@用户名、好友、聊天和共享看板，游戏邀请保存 10 分钟。谁在线只保存在内存中，持续一分半钟。会话密钥只发送到 Arcade 的网站。
- 笔记本和日历保留在你的电脑上。共享看板和聊天一样保存在 Arcade 的网站上，且没有加密。只有在你要求时，页面才会通过你自己的 Claude 连接器发送到 Notion 或其他应用；跟踪器中的 issue 和评论也是如此 — Arcade 本身从不与 GitHub、Linear、Jira 或其他跟踪器通信。
- *智能体* 通过 `~/.claude/arcade/agents` 中的小文件看到你的其他会话 — 每个会话的文件夹、状态和卡片、它在等待的问题或授权请求的文字和命令，以及它的上下文、费用和限额窗口。从 *智能体* 发出的回答也放在旁边。这些文件留在这台电脑上，绝不会发送到 Arcade 的网站；和以前一样，在共享看板上好友只能看到“领取人 @handle”。在 git 文件夹中，会话的文件还记有它的分支和改动文件的名称及行数 — 由 git 在该会话自己的文件夹里读取，不会发送到任何地方；Arcade 从不提交、回滚，也不会把任何东西放进 stash。
- 错误报告只包含你的文字、Arcade 版本、打开的位置、界面语言和操作系统 — 别无其他；未登录时以匿名方式发送，网站也不会保存任何地址。
- 部分游戏只有在你要求时才会访问互联网 — 例如 OpenTTD 的可选调查和它的 *Online Content* 按钮。

## 反馈

发现了错误？最快的方式是直接在 Arcade 中报告：**更多 → 🐞 报告错误**。描述出了什么问题，报告就会连同版本、运行环境、语言和操作系统一起直接发送给 Arcade 的作者。

你也可以提交 [issue](https://github.com/ArbakovMaxim/agent-arcade/issues) — 错误和想法都可以。请注明你的操作系统、Claude Code 运行环境（终端、VS Code 或 Desktop）以及游戏名称。

欢迎提交拉取请求。提交即表示你同意你的贡献以 AGPL-3.0 授权，并且作者也可以以其他条款（例如商业许可证）提供 Arcade。

## 面向开发者

```
mod/     Claude Code 插件（钩子、面板界面、测试）
site/    运行在 Cloudflare Workers 上的网站：目录、Arcade 窗口、联网房间、账户、好友、聊天、错误报告
tools/   构建辅助工具：翻译、heretic-wasm
.github/ 为浏览器构建 doom-wasm、heretic-wasm、OpenTTD 和 ScummVM 的 GitHub Actions
```

- 从仓库运行插件：`claude --plugin-dir ./mod`
- 插件测试：`claude plugin validate ./mod`，然后在 `mod/` 中运行 `claude plugin test`
- 网站测试：在 `site/` 中运行 `npm test`；构建：`node build.mjs`；通过 Cloudflare Workers Builds 从 `main` 自动部署。
- 开发在 `main` 上进行，Pull Request 也请提交到 `main`。默认分支 `plugin` 是去掉 `site/` 的 `main` 副本，每次推送时由 GitHub Action 更新：插件市场下载的是这个分支，而不是整个仓库。
- 翻译：`node tools/i18n/collect.mjs`，然后 `node tools/i18n/check.mjs` — 见 [tools/i18n/README.md](tools/i18n/README.md)。

详细文档（俄语）：[mod/docs/README.ru.md](mod/docs/README.ru.md) — 插件，[site/README.md](https://github.com/ArbakovMaxim/agent-arcade/tree/main/site/README.md) — 网站、添加游戏和联网对战。
