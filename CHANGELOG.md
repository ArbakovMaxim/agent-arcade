# Changelog · Список изменений

## 0.21.0 — вход через GitHub, по желанию: плитка «Войти через GitHub» в главном меню; Arcade показывает код, человек вводит его на странице GitHub в обычном браузере — и язык, клавиши, уведомления, размер панели, что делать с игрой по сигналу агента, свои темы, каналы Twitch и рекорд Flappy Arcade становятся одними на всех его компьютерах; без входа всё работает, как раньше · sign in with GitHub, optional: a “Sign in with GitHub” tile in the main menu; Arcade shows a code, you enter it on the GitHub page in your regular browser, and your language, keys, notifications, panel size, what to do with the game when the agent signals, your topics, Twitch channels and Flappy Arcade best become the same on all your computers; without signing in everything works as before

- Arcade learns only your GitHub profile name and picture: no email, no access to repositories; the site uses the GitHub token once to learn who you are and forgets it at once; the mod keeps only Arcade’s own session key, sent only to Arcade’s site · Arcade узнаёт только имя и картинку профиля GitHub: ни почты, ни доступа к репозиториям; токен GitHub сайт использует один раз — узнать, кто ты, — и сразу забывает; у мода — только ключ сессии Arcade, и уходит он только на сайт Arcade
- Sync: a changed setting goes to the site a couple of seconds later; the mod also syncs shortly after start, every half hour and when the account menu opens; for each setting the later change wins, and for the Flappy Arcade best the higher score; a value from the site the mod does not understand is replaced with the local one · синхронизация: изменённая настройка уходит на сайт через пару секунд; ещё мод синхронизируется вскоре после старта, раз в полчаса и при открытии меню аккаунта; у каждой настройки побеждает более позднее изменение, у рекорда Flappy Arcade — больший счёт; значение с сайта, которое мод не понимает, заменяется здешним
- What stays per computer: your own games, the catalog, the last game, the browser and the graphics mode · у каждого компьютера своё: свои игры, каталог, последняя игра, браузер и графика
- “Sign out” stops syncing on this computer; “Delete account” (press twice) makes the site forget you and your settings; in both cases the settings here stay as they are · «Выйти» прекращает синхронизацию на этом компьютере; «Удалить аккаунт» (двумя нажатиями) — сайт забывает тебя и твои настройки; в обоих случаях настройки здесь остаются как есть
- The site (`/api/auth/*`, `/api/me`) uses GitHub’s device flow, with no client secret; sign-in attempts per address are limited per day · сайт (`/api/auth/*`, `/api/me`) входит через device flow GitHub, без секрета приложения; попытки входа с одного адреса ограничены за сутки
- New strings are translated into all 13 languages · новые строки переведены на все 13 языков
