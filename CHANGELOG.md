## 0.48.0 — Проверка между карточками · Check between cards

- On a board screen, *Check between cards* takes a command such as `npm test`, and a card can have *This card's check* of its own. When Claude ends a turn with the queue's card in the last column, the queue runs the command in the session folder (for up to 10 minutes) before giving the next card · на экране доски поле «Проверка между карточками» принимает команду вроде `npm test`, а у карточки может быть «Своя проверка». Когда Claude заканчивает ход, а карточка очереди уже в последней колонке, очередь запускает команду в папке сессии (не дольше 10 минут) и только потом отдаёт следующую карточку
- Exit code 0 — the next card goes. Any other code, a timeout or a command that doesn't start stops the queue: the card goes back to the second column (the first on a two-column board) marked *⚠ Check failed — code 1, 14:05*, and Claude gets the command, the result and the last 40 lines of output to fix it and move the card again. Starting the queue again checks that card first: once it passes, the mark goes and the queue moves on · код 0 — следующая карточка уходит. Любой другой код, вышедшее время или команда, которая не запустилась, останавливают очередь: карточка возвращается во вторую колонку (в первую, если колонок две) с пометкой «⚠ Проверка не прошла — код 1, 14:05», а Claude получает команду, итог и последние 40 строк вывода, чтобы исправить и перенести карточку снова. Новый запуск очереди сначала проверяет эту карточку: прошла — пометка снимается, и очередь идёт дальше
- The board shows the running check and the last result with the end of its output. The day log and the *Daily summary* get a *Checks between cards* section, and a card whose last check failed after it was moved to the last column no longer counts as done · на доске видно идущую проверку и последний итог с концом вывода. В журнал дня и «Итоги дня» попадает раздел «Проверки между карточками», а карточка, чья последняя проверка не прошла уже после переноса в последнюю колонку, больше не считается сделанной
- With the queue in several sessions, the session that did the card runs its check, and only that session rechecks the card on the next start · если очередь идёт в нескольких сессиях, проверку запускает та, что делала карточку, и только она перепроверяет её при новом запуске
- The command runs without a permission prompt, like a Claude Code hook, through `cmd.exe /d /c` on Windows and `sh -c` elsewhere. It is set only on the board screen and kept only on this computer, in the plugin's local store: not in the notebook, not on a shared board and not visible to the `mcp__arcade__notes` tool — so neither Claude nor board members can set or change it · команда идёт без запроса разрешения, как хук Claude Code, — через `cmd.exe /d /c` на Windows и `sh -c` на других системах. Её задают только на экране доски, и хранится она только на этом компьютере, в локальном хранилище плагина: не в блокноте, не на общей доске и не видна инструменту `mcp__arcade__notes`, так что ни Claude, ни участники доски её не зададут и не поменяют
- No command — the queue works as in 0.47 · нет команды — очередь работает как в 0.47
- The README in all 13 languages describes the check, and *What the plugin does on your computer* lists its command; the new lines are translated into all 11 other interface languages · в README на всех 13 языках — проверка между карточками, а в «Что плагин делает на твоём компьютере» — её команда; новые строки переведены на все 11 других языков интерфейса
- New tests: exit 0 and the next card; exit 1 with the card sent back, the mark, the stopped queue and the output passed to Claude; a fixed card rechecked on the next start; a card's own command; a timeout; no command; checks in the day log and the summary. The tests run on Claude Code 2.1.302 and on 2.1.316 · новые тесты: код 0 и следующая карточка; код 1 — карточка назад, пометка, очередь стоит, вывод ушёл Claude; исправленная карточка перепроверяется при новом запуске; своя команда карточки; вышедшее время; без команды; проверки в журнале дня и в итогах. Тесты проходят на Claude Code 2.1.302 и на 2.1.316
